# claude_brain 인수인계 (새 세션에 붙여 넣기용)

> 이 문서를 새 세션의 첫 메시지로 붙여 넣는다. 2026-11-03 기준.
> **이 작업은 `claude_brain` 저장소만 다룬다. `woong_stock`(주식 데이터 수집 저장소)은 건드리지 않는다.**

## 1. 목표
- Claude 의 "제2의 뇌": 여러 세션의 대화·결과를 md 로 남겨, 다음 세션이 이어서 일하게 한다.
- 옵시디언 볼트로도 연다. 사용자의 **주식 정보 볼트와는 완전히 별도** (파일·동기화 모두 분리).

## 2. 지금까지 된 것
- GitHub 비공개 저장소 **`woong2399/claude_brain`** 생성(사용자) → `main` 에 push 완료.
- Claude GitHub 앱에 `claude_brain` 접근 권한 추가 완료(사용자). 클라우드 세션에서 push 가능.
- 구조:
  ```
  claude_brain/
  ├─ CLAUDE.md        Claude 규칙 (시작 시 읽을 것, 끝날 때 기록할 것, 섞지 않는 규칙)
  ├─ 00_Index.md      목차: 진행 중 프로젝트, 최근 세션
  ├─ Sessions/        세션 기록 (YYYY-MM-DD-프로젝트-주제.md, frontmatter project: 필수)
  ├─ Knowledge/       오래 쓸 지식 (사용자.md)
  ├─ Inbox/           사용자가 Claude 에게 남기는 메모
  ├─ Templates/       session.md, project.md
  └─ Projects/<이름>/  README.md(요약) · docs/(상세 문서) · code/(코드 조각·SQL)
      ├─ woong_stock/   docs 에 woong_stock 문서 4개 사본(기준일 11-03), code 에 조회-SQL.md
      └─ claude_brain/
  ```
- 결정:
  - 프로젝트 폴더 안을 README / docs / code 세 칸으로 나눠 섞지 않는다 (사용자 요청).
  - 수집 프로그램 전체 코드는 복사하지 않는다 (두 벌이면 최신본이 엉킴). 원하면 바꿀 수 있음.
  - 비밀값(키·토큰·비밀번호)은 저장소에 적지 않는다.
  - 이름은 `claude_brain` (밑줄).

## 3. PC 쪽 설정 — ✅ 완료 (2026-11-03, 사용자 확인; 아래는 다시 할 때의 절차)
1. **사용자:** PC 에서 Remote Control 켜기
   - 볼트를 둘 상위 폴더를 정한다 (예: `C:\Users\<이름>\Documents\Obsidian`. 홈 폴더 자체·숨김 폴더 불가).
   - Claude 데스크톱 앱 → 설정 → Claude Code → Remote Control 에 그 폴더 추가 (또는 그 폴더에서 `claude remote-control`).
   - 직전 세션에서는 등록된 폴더가 0개였다.
2. **Claude (원격):** 그 폴더에 `git clone https://github.com/woong2399/claude_brain.git`, push/pull 되는지 확인.
3. **사용자 (옵시디언 화면):** "폴더를 볼트로 열기" → `claude_brain` / 커뮤니티 플러그인 **Obsidian Git** 설치·켜기.
   - Pull on startup: 켜기 / Auto commit-and-sync interval: 10분
   - 클라우드 세션 네트워크에서는 플러그인 배포처가 막혀 Claude 가 미리 받을 수 없었다.
4. **시험:** 새 세션에서 저장소에 `claude_brain` 을 선택하고 "claude_brain 읽고 시작해" → 이어지는지 확인.

## 4. 사용 방법 (완성 후)
- 세션 시작: 저장소 목록에서 `claude_brain` 도 선택 → "claude_brain 읽고 시작해".
- 세션 끝: "기록해줘" → Claude 가 Sessions 노트 작성, Projects 요약·Index 갱신, push.
- 사용자 메모: 옵시디언에서 `Inbox/` 에 적어 두면 다음 세션이 처리.
