# 2026-11-05 News 배치파일 — 상세

요약: [[2026-11-05-배치파일]]

## 대화 흐름
1. 사용자가 "179건이 한경에서 11월 1일에 발행된 뉴스 전부냐, 생각보다 적다"고 물음. 같은 사이트맵으로 10/26~11/04 날짜별 건수를 비교해 답함(아래 표). 사이트맵 기준으로는 주말 패턴과 맞지만 한경 자체 목록과는 대조하지 않았다고 알림.
2. 사용자 요청: "지금 한 과정을 코드로 만들고 배치파일 만들어줘, 수집 전에 날짜를 지정할 수 있게". 이어서 "news 폴더에 넣으면 돼", "구글 스프레드 시트 저장까지".
3. 구현·시험 후, 사용자가 시트 설정 방법을 물음 → 5단계 안내. 사용자가 "앱 스크립트를 눌렀더니 구글 드라이브에서 해달래" → 코드에 `SHEET_ID` 속성 지원을 넣고 `script.google.com` 새 프로젝트 방법 안내.
4. 사용자 질문들: "내 컴퓨터에서 해야 해?"(Apps Script 설정은 브라우저 어디서든, `.env`·실행은 이 PC), "이게 뭘 하는 건데?"(시트에 글 써 주는 심부름꾼이라고 비유 설명). 결론: **시트 설정은 나중에**.
5. "일단 기록해줘" → `Projects/News/` 에 기록(이 노트).

## 구현 메모
- `run_news.py` 흐름: 날짜 입력 → 날짜별로 사이트맵에서 링크 목록 → DB 에 있는 것 제외한 신규 건수 → 합계·예상 시간(기사당 약 2.6초) → `Y/n` → `hankyung.collect` → 실패가 있으면 5초 뒤 1회 재시도 → CSV(`utf-8-sig`, 엑셀·시트에서 한글 안 깨짐) → 시트(`.env` 설정 있을 때만). `--from/--to/--yes` 로 묻지 않고 실행 가능.
- `sheets.py`: `.env` 의 `SHEETS_WEBAPP_URL`, `SHEETS_TOKEN` 을 읽어 200행씩 POST(JSON). Apps Script 가 주소를 한 번 넘겨주는데 urllib 이 따라간다. 토큰이 틀리면 `bad token` 오류.
- `apps_script.gs`: `doPost` 에서 토큰 확인 → 탭이 없으면 만들고 머리글 → G열(링크)에 이미 있는 행 제외 → 날짜·시각 열은 글자 형식으로 덧붙임. 스크립트 속성 `TOKEN`(필수), `SHEET_ID`(따로 만든 프로젝트일 때).
- 시험 중 결함: `sheets.load_env(path=ENV_PATH)` 기본값이 정의 시점에 고정돼 경로를 바꿀 수 없었다 → `path=None` 으로 고침. 가짜 HTTP 서버로 업로드 시험.
- 처음 `-I` 옵션으로 돌렸다가 `import db` 가 안 된 일, 한글이 터미널에 깨져 보인 일(cp949)은 [[2026-11-05-한경수집-상세]] 참고. 배치파일은 `chcp 65001`, `PYTHONUTF8=1` 로 해결.

## 시트 설정 안내(사용자에게 한 내용 요약)
Apps Script 새 프로젝트 → `apps_script.gs` 붙여 넣기 → 스크립트 속성 `TOKEN`(긴 임의 문자열), `SHEET_ID`(시트 주소의 `/d/` 와 `/edit` 사이) → 웹 앱 배포(실행 사용자 나, 액세스 모든 사용자) → 웹 앱 URL 과 토큰을 `news\.env` 에 직접 적기. 값은 채팅에 붙이지 않는다.
