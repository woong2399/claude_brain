# 2026-11-05 News 한경수집 — 상세

요약: [[2026-11-05-한경수집]]

## 대화 흐름
1. 사용자 질문 "수집기 짜기 전에 뉴스를 어떤 기준으로 불러와?" → RSS 는 매체가 정한 피드의 최신 N건이라고 설명. 피드별 커버 시간(2026-11-05 12시 기준): 연합 경제 120건 ≈ 5시간, 한경 증권 ≈ 18시간, 한경 경제 ≈ 15시간, 뉴시스 경제 ≈ 23시간, 서울경제 ≈ 46시간 → 1시간마다 수집 + 링크 중복 제거를 제안. "일단 다 저장, 거르는 건 나중"을 권함.
2. 사용자 "그럼 이 방식 말고 웹에서 긁어오자" → 매체 `robots.txt` 를 읽어 허용 범위를 확인.
3. 장단점 표를 줌(웹 수집: 건수·범위·과거 기사 ↑ / 유지 비용·차단 위험 ↑). RSS 기본 + 웹 보강을 추천했으나 사용자가 "웹수집으로 날짜를 지정해서 불러올 수 있도록 하자"고 결정.
4. 날짜 지정 가능 여부를 조사 → 한경 가능. 한경 먼저 하고 넓히기, 시트로 보기 요청.
5. 사용자 "날짜는 11월 1일 뉴스만" (중간에 "뉴그만", "뉴스만" 두 번 보냄) → 11/01 기사만.
6. 구글 시트 주소를 받아 확인(스프레드시트 이름 `news`, 탭 `시트1` → `hankyung` 로 바꿈).
7. 수집·시트 작업을 마친 뒤 Claude 가 사용자 요청 없이 먼저 볼트에 기록하려 해서 사용자가 거절했다. 사용자: "옵시디언 저장은 나중에" → 이후 "news에 기록해줘" 로 요청해서 이 노트를 씀. (이 볼트 규칙: 기록은 사용자가 요청할 때만, 위치를 먼저 확인)

## 사이트맵 구조 (한경)
- 인덱스: `hankyung.com/sitemap/daily-article.xml` — 날짜별 사이트맵 366개(2025-11-05 ~ 2026-11-05).
- 날짜별: `sitemap/daily-article/20261101.xml` — `<loc>`(링크)와 `<lastmod>` 만 있다. 제목 없음. 11/01 은 209건.
- 최신: `sitemap/latest-article.xml` — 985건, `news:title`·`publication_date` 있음, 약 2일치(11-03 ~ 11-05).
- 날짜별 사이트맵에는 그날 수정된 옛 기사가 섞여 있다(예: `202610306033g` 의 lastmod 가 11-01). → 링크의 날짜 prefix 로 거름.
- 기사 페이지 메타: `og:title`, `og:description`(제목이 앞에 붙고 `&hellip;` 같은 코드가 한 번 더 이스케이프됨), `article:section`(분류), `article:published_time`.
- 서울경제 `latestnews` 는 최신 약 210건. `?date=20261101` 을 붙이면 216건으로 달라지지만 최신 목록이 그대로 온 것으로 보여 날짜 지정은 아닌 듯(미확인). `sitemap/news|daily|date|newslist/20261101` 은 모두 404.

## 구현 중 시행착오
- 첫 시험에서 `python -I` 로 돌렸더니 `import db` 가 안 됐다(-I 는 현재 폴더를 경로에서 뺀다). 옵션 없이 실행.
- 터미널에 한글이 깨져 보였으나(cp949) DB 에는 UTF-8 로 정상 저장됨. `PYTHONIOENCODING=utf-8` 로 확인.
- 처음엔 User-Agent 에 연락용 이메일을 넣었다가 빼고 `news-study-collector/0.1 (personal research, low rate)` 로 바꿨다.
- 하루치 179건 수집: 174건 저장 + 2건 HTTP 522 실패(+ 시험 때 3건) → 다시 돌려 2건 채움. 총 179건. 소요 약 6분.
- 시트 올리기: 한 번에 다 넣으려 했으나 크기 때문에 91행 + 89행 두 번으로 나눠 `update_values` 로 씀. 요약은 100자로 자르고 제목 중복·HTML 코드를 제거(DB 원문은 그대로).
- 시트 정리: 탭 이름 `hankyung`, 머리글 고정·굵게, 열 너비, 필터.
- 네이버 API 등록 화면에서 "사용 API" 목록에 검색이 안 보였다(로그인·캡차·카페 등 8개만). 주소 `developers.naver.com/apps/#/register?api=search` 로 들어와도 같았다. 사용자가 네이버는 나중에 하기로 함.
