# 2026-11-03 Brain — 셋업

## 한 줄 요약
여러 세션 대화를 이어가기 위한 기억 저장소를 주식 볼트와 **별도로** 만들었다.

## 결정 (이유)
- **별도 저장소 + 별도 옵시디언 볼트**: 주식 정보 노트와 Claude 기록이 섞이지 않게. 동기화 범위도 이 볼트만.
- **GitHub 경유**: 클라우드 세션은 사용자 PC 를 직접 못 본다. GitHub 은 웹·모바일·PC 세션 모두 접근 가능.
- **요약 + 링크만**: 코드·상세 문서는 프로젝트 저장소에 두고 여기서는 가리키기만 한다. 중복 관리 방지.
- **비밀값 금지**: 저장소에는 키·토큰을 적지 않는다.
