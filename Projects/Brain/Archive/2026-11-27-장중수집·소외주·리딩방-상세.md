# 상세 — 11-18~11-25 작업 흐름

## 1. 장중 실시간 수집기
### 흐름
- 시황 질문(아난티가 왜 올랐나) → 거래대금 상위·10% 상승을 실시간으로 보여 달라 → "100위 + 10%" 기준 유지, 프로그램 매수 방향·신규성·재료 추가 → "코드로 짜줘" → 재료 없으면 테마 동향 → 테마별 거래대금·프로그램 유입 보고 → 보고 간격(1시간은 적다 → 30분 → 10시까지 10분) → "로그에 줄줄이" → "ETF 빼고 100위".

### 구성
- `storage/live.py`, 명령 `python -m storage live`, 실행 `scripts/run_live.sh`, 테스트 `tests/test_live.py`(당시 전체 137 통과)
- 장중 데이터는 `data/live.duckdb`(live_rank, live_program, live_alert, live_theme). 본 DB 는 읽기 전용
- 키움 TR: ka10032(거래대금 상위, 100행씩, 다음 페이지 조회), ka10027(등락률), ka90004(전 종목 프로그램, 약 112회·38초, 백만원), ka90001/90002(테마)
- 네이버 공개 테마: `m.stock.naver.com/api/stocks/theme` 265개, 2,380종목, 약 36초
- 뉴스: `assistant\news\data\rss\news.db`, 최근 24시간 제목 3개
- 시간: 09:00~15:35, 프로그램 5분마다 갱신

### 시행착오
- 문자열 치환 중 f-string 안에 실제 줄바꿈이 들어가 SyntaxError. `eb162eb` 는 `| tail` 이 테스트 실패를 가려 **문법 오류인 채 push** → `bc88a1a` 에서 고침. 테스트 결과를 파이프로 자르지 않는다.
- 테스트 기대값 오류(반도체 순매수 +4,700 은 유입), REPORT_TIMES 치환 문자열 불일치.
- 백그라운드를 죽이고 다시 띄우면 exit 127 이 뜨는 것은 kill 때문(정상).
- ETF 를 빼면 100개가 안 채워져 다음 페이지 조회 추가(`86e107a`). 바뀐 직후 진양산업·에스피소프트·인제니아테라퓨틱스 알림.
