## 시행착오
- **`sed` 사고:** 이름 변경 중 `sed -e 's/\\|Stock_storage\]\]/.../'` 의 `\\|` 가 GNU sed 에서 "빈 문자열 또는 ..." 대체 패턴으로 해석돼, **모든 마크다운 파일의 모든 줄 앞에** `|Brain]]|Storage]]` 가 붙었다. 커밋 전에 발견했다. 내용 변경은 아직 스테이징 전이었으므로 `git checkout -- .` 로 되돌리고(폴더 이동은 `git mv` 로 이미 스테이징돼 유지), Python `str.replace` 로 다시 했다. 교훈: 한글·`|`·`\` 가 섞인 치환은 sed 대신 Python 으로 한다.
- 첫 시도는 `sed` 의 구분자 `#` 가 패턴의 `# 제목` 과 겹쳐 실행 전에 오류로 끝났다. (폴더 이동만 적용됨)
- `cd` 한 뒤 작업 디렉터리가 `docs/` 로 바뀐 채 이어져서 경로를 다시 확인했다.
- `handoff-chat.md` 에서 줄 번호로 지울 때 코드 블록의 닫는 ``` 까지 지워서, 맨 끝에 다시 붙였다.
- 한 번은 push 직전에 다른 세션이 올린 커밋(Daily 17종목, Storage 수집 방식 변경)이 이미 들어 있었다. 충돌은 없었다.
