# 일지 형식 (Daily stocks 보관함)

원본은 보관함 `C:\Users\Jinwo\OneDrive\문서\Daily stocks` (기준일 2026-11-03). 이 문서는 사본·요약이다.

## 한 줄 규칙 (한 종목 = 한 줄)
```
- [[종목]] [등락:: 9.80] [[테마]] [[테마]] (사유:: 원문 사유)
```
- **등락은 대괄호, 사유는 소괄호.** CSS가 괄호 모양으로 구분한다 (순서로 구분하면 폰에서 깨짐).
- **테마 링크는 사유 괄호 밖**에 둔다. 안에 넣으면 테마로 인식되지 않는다.
- 파일 이름에 `/`를 못 쓰므로 테마 이름은 `·`로 (예: `방위산업·전쟁 및 테러`).
- 테마 링크 철자는 테마 노트 이름과 **똑같이** (띄어쓰기까지). 자동완성으로 고르면 안전.

## 폴더
- `일지/YYYY-MM-DD.md` (frontmatter: `cssclasses: ds-journal`, `날짜`)
- `종목/<종목>.md` (코드 + "날짜별 이슈" Dataview 목록)
- `테마/<테마>.md` ("종목" 목록 + "급등 기록" Dataview)
- `테마 트리.md` (Dataview JS, 테마 ▸ 종목 ▸ 이슈)
- `템플릿/` (일지·종목·테마)

## 자동 모음 쿼리 (테마 노트)
```
LIST WITHOUT ID key
FROM "일지"
FLATTEN file.lists AS L
WHERE contains(L.outlinks, this.file.link)
GROUP BY L.outlinks[0]
SORT key ASC
```
- `L.outlinks[0]` = 줄의 첫 링크 = 종목. 이 줄에 그 노트(테마/종목)로 가는 링크가 있으면 모인다.

## 새 테마 만들기 (사용자가 하는 법)
1. 일지 줄에 `[[테마명]]` 추가 (자동완성).
2. 처음 쓰는 테마면 `테마/` 폴더에서 새 노트를 같은 이름으로 만들고 `Templater: Insert template` → 테마 템플릿.
