## 한 줄 규칙 (한 종목 = 한 줄)
```
- [[테마]] || [[종목(코드)]] +등락률%<br>이슈
```
- 예: `- [[보안주(정보)]] || [[한싹(430690)]] +29.96%<br>대통령 순방단 개인정보 유출 … 상한가`
- 테마가 여럿이면 `[[테마]] [[테마]] ||` 처럼 이어 쓴다.
- **테마 미지정이면 `[[Null]]`.** Null 노트의 목록에서 테마를 못 정한 종목을 한눈에 본다. 테마를 정하면 `[[Null]]` 은 지운다.
- `||` 는 세로선 `|` 키(`Shift+\`)를 두 번. 앞뒤에 띄어쓰기 한 칸.
- 이슈는 같은 줄 안에서 `<br>` 뒤에 쓴다. 화면에는 아랫줄로 보인다. 아랫줄 하위 항목으로 쓰면 노트 안 검색 결과에 이슈가 안 보인다.
- 테마·종목은 진하게 하지 않는다 (시도했다가 뺌).
- 파일 이름에 `/`를 못 쓰므로 테마 이름은 `·` 로 (예: `정치 · 인맥(오세훈)`). 링크 철자는 노트 이름과 똑같이(띄어쓰기까지). `[[` 자동완성으로 고르면 안전.

## 폴더
- `일지/YYYY-MM-DD.md` — 머리말 `날짜` 는 없어도 된다(검색·트리가 파일 이름을 씀).
- `종목/<종목(코드)>.md` — 머리말 `코드: "430690"`, "날짜별 이슈" 아래에 검색 블록.
- `테마/<테마>.md` — "종목 · 급등 기록" 아래에 검색 블록. `테마/Null.md` 는 미지정용.
- `테마 트리.md` — Dataview JS (PC 전용. 폰에서는 코드로 보임).
- `템플릿/` — 일지·종목·테마 (코어 템플릿 플러그인용).

## 노트 안에 목록이 보이는 방법 (코어 검색 블록)
````
```query
path:일지 "[[한싹(430690)]]"
```
````
- 종목 노트는 `"[[종목(코드)]]"`, 테마 노트는 `"[[테마]]"` 를 검색한다. 일지에서 그 링크가 적힌 줄이 노트 안에 나온다. 백링크 패널을 열지 않아도 된다.
- 템플릿에서는 `"[[{{title}}]]"` 라고 쓰면 노트 이름으로 바뀐다.
- 미확인: 검색 결과에서 `<br>` 가 글자로 보이는지, 폰에서 되는지.

## 일지 만들기
- 오늘 것: 명령어 팔레트 "일일 노트 열기" (설정: 새 파일 위치 `일지`, 날짜 형식 `YYYY-MM-DD`, 템플릿 `템플릿/일지 템플릿.md`). 오늘 날짜만 만든다. **사용자가 "안 된다"고 했고 증상은 미확인.**

## 새 종목·테마 노트 만들기 (사용자가 하는 법)
1. `종목/` 폴더에 새 노트를 `종목(코드)` 이름으로 만들고 템플릿 삽입 → `종목 템플릿`. 머리말 `코드:` 에 코드를 따옴표로 쓴다.
2. 새 테마면 `테마/` 폴더에 같은 이름으로 만들고 `테마 템플릿` 삽입.
- 노트가 없어도 일지에서 링크는 만들어지지만(회색), 노트 안 목록은 노트가 있어야 보인다.

## 템플릿 주의 (YAML)
- 머리말 값에 `{{ }}` 를 쓸 때는 **반드시 따옴표**: `날짜: "{{date:YYYY-MM-DD}}"`. 따옴표가 없으면 YAML 객체로 읽혀 속성 편집기가 값을 깨뜨린다.
