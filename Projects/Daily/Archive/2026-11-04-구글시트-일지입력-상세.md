## 시트를 채운 과정과 막힌 점
- 빈 스프레드시트는 Drive `create_file`(미디어 형식 `application/vnd.google-apps.spreadsheet`)로 만듦. 내용이 없는 생성이라 이름만 `Daily 일지 입력`.
- 처음에 `update_values` 로 한 줄을 시험했더니 **입력값이 USER_ENTERED 처럼 해석**됨: `"004545"` → 숫자 `4545`(앞자리 0 사라짐), `"2026-11-03"` → 날짜 값(표시는 `2026-11-03` 로 유지).
- 해결: 코드 앞에 `'` 를 붙여 `"'004545"` 로 쓰면 글자로 저장됨 (읽으면 `004545`). 날짜는 날짜 값으로 두어도 `get_values` 가 `2026-11-03` 으로 돌려줘서 그대로 둠.
- 전체 쓰기 범위 `시트1!A1:G70` (머리글 1행 + 69행). 읽기 확인에서 앞자리 0 과 영문 섞인 코드(`18064K`, `0053F0`, `0015M0`, `0220W0`) 모두 보존.
- 69행은 Surge CSV 두 개(`C:\Users\Jinwo\Documents\surge\2026년 11월 2일.csv`, `…3일.csv`)를 PowerShell `Import-Csv` 로 읽어, 날짜 내림차순·등락률 내림차순으로 정렬해 만듦.

## 시트와 옵시디언 일지의 관계
- 시트 한 장에 날짜별로 행이 쌓이는 구조 (날짜 열로 구분).
- 옵시디언 일지에는 이미 11/02(48줄)·11/03(21줄)이 `[[Null]]` 과 빈 이슈·기사로 만들어져 있다 ([[2026-11-04-surge-csv-일지입력]]). 시트에서 옮길 때 이 줄들을 어떻게 할지(덮어쓰기/건너뛰기)가 미정.
- 옮길 줄 모양(제안): `- [[테마]] [[테마]] || [[종목(코드)]] +00.00%<br>이슈<br>[기사](뉴스링크)`; 테마가 비면 `[[Null]]`.

## 시도했다 버린 방법
- 웹에 게시한 CSV 주소 읽기 (공개 노출).
- 브라우저를 직접 조작해 시트 읽기 (느리고 불안정).
- 코드 열을 그냥 문자열로 보내기 (시트가 숫자로 바꿔 앞자리 0 이 사라짐).
