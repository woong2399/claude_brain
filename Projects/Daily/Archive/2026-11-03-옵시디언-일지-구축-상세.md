# 상세 기록

## 출발점
- 사용자는 매일 급등일지(텔레그램 "타점 읽어주는 여자" 채널 글 기준)를 쓰고 테마별로 종목을 분류한다. 이를 옵시디언에 `테마 > 종목 > 날짜별 이슈`로 정리하길 원했다.
- 옵시디언을 직접 열어 보니 PC 보관함은 폰(`Daily stocks`, 안드로이드 `Documents/Daily stocks`)과 **다른 보관함**이었다. 폰은 어디에도 동기화돼 있지 않았다.

## 초기화
- 사용자가 "보관함 폴더까지 삭제"를 골랐으나 노트에 개인 정보가 섞여 있어, 영구 삭제 대신 **이름 변경 → 휴지통**으로 처리했다. 보관함 경로는 `문서` 전체가 아니라 그 안의 `Obsidian Vault` 하위 폴더였다 (처음에 화면에서 경로가 잘려 보였음).
- 옵시디언 앱 설정 폴더(`%APPDATA%\obsidian`)도 같은 방식으로 휴지통.

## 구조 시행착오 (순서대로)
1. `테마/종목/일지` 폴더 + 이슈를 **개별 노트**로 → 하루 20~30개라 너무 많음 → 폐기.
2. 날짜별 일지 1개에 줄로 모으기 + 종목/테마 노트는 검색 쿼리 임베드 → 채택.
3. Dataview로 표를 만들었다가 사용자가 **표·등락률 배지를 싫어해서 제거**. 종목·테마 노트는 한 줄 목록(`LIST`)으로 바꿈.
4. 테마에 종목 목록 섹션을 추가 (일지에서 그 테마 링크가 붙은 종목을 자동 모음).
5. 나무가지 형태 요청 → Dataview JS로 `테마 트리.md` (테마 ▸ 종목 ▸ 날짜별 이슈, 접고 펼침). 이를 위해 Dataview JS 설정을 켬.

## 플러그인
- Dataview: 인라인 필드(`등락::`, `사유::`)와 쿼리. 처음에 PC 옵시디언이 1.12.7이라 최신 Templater(요구 1.13)가 안 켜져 2.20.6을 깔았다가, 옵시디언을 **1.14.5로 업데이트**한 뒤 Templater 2.26.0으로 올림. 올리면서 "새 파일 생성 시 자동 실행"이 기기별 설정으로 바뀌어 꺼짐.
- Calendar 1.5.10 (최신은 베타라 안정 버전 사용). Style Settings 1.0.9 (색·표 크기·본문 폭 옵션 노출).

## 디자인 (CSS 스니펫)
- 일지 노트에 `cssclasses: ds-journal`. 한 종목을 **2줄 카드**(1줄: 종목 · 빨간 +등락률% · 테마, 2줄: 회색 사유)로 보이게 함.
- 폰에서 사유까지 빨갛게 나온 문제: 처음엔 "첫 필드=등락, 두 번째 필드=사유"처럼 **순서**로 CSS를 짰는데 폰 렌더링에서 어긋남 → 등락은 대괄호 `[등락:: n]`, 사유는 소괄호 `(사유:: …)`로 바꾸고 모양으로 구분.
- 다크 모드에서 테마 트리 글자가 안 보임 → 다크용 밝은 색 변수, 테마 이름은 본문색으로. `color-mix()`는 일반 색값으로 교체.

## 11/02 데이터 입력
- 텔레그램 글을 붙여 넣어 42종목 입력. 등락률·사유는 원문 그대로. 파일 이름에 못 쓰는 `/`는 **테마 이름에서만** `·`로 바꿈.
- 테마는 원문에 "○○ 테마 상승"이라고 명시된 것만 연결 (예: 조선기자재, LNG(액화천연가스), 철강 주요종목, 정치·인맥(한동훈), 태양광에너지 등). `반도체 관련주`, `HLB 그룹주`처럼 "테마"라는 말이 없는 종목(약 20개)은 비워 두고 사용자가 직접 입력.
- 테마 노트 `철강 주요종목`을 사용자가 `철강`으로 이름을 바꿔서 일지의 링크 2곳을 맞춰 줌.

## 폰 동기화 (Syncthing)
- PC에 Syncthing v2.1.7을 GitHub 릴리스에서 받아 체크섬 확인 후 `%LOCALAPPDATA%\Programs\Syncthing\`에 설치, 숨김 실행.
- 폴더 id `daily-stocks`, 표시 이름 `woong_stocks`. `.stignore`로 `workspace.json`, `workspace-mobile.json`, `.trash` 제외.
- 사고: API로 폴더 설정을 가져와 그대로 다시 저장했더니 **한글 경로가 깨져 저장**됨(`문서` → 깨진 글자). 바로 PATCH로 원래 경로 복구. 깨진 경로로 만들어진 폴더는 없었음을 확인.
- 폰(Syncthing-Fork)이 처음엔 연결되지 않았고, 폴더 공유 알림이 안 떠 폴더 이름을 `woong_stocks`로 바꿔 다시 제안하자 연결·수락되어 **100% 동기화**.
- 폰의 옛 `Daily stocks` 보관함은 건드리지 않음. 폰에서는 새 폴더(`Documents/woong_stocks`)를 보관함으로 열도록 안내.
- PC 시작 시 자동 실행 등록 시도는 권한 확인에서 막혀 하지 않음.

## 사용자 선호 (대화에서 확인)
- 표·배지 싫어함, 가독성(깔끔함) 중시.
- "어떻게 해?"라고 물으면 **방법만** 알려 주길 원함 (직접 고치지 말 것).
- 테마는 임의로 넣지 말고 확인되는 것만, 나머지는 본인이 입력.
