# Daily (주식 일지)

## 한 줄 설명
매일의 주식 일지를 쓰는 곳. 파일 이름은 날짜로 시작한다 (`Sessions/YYYY-MM-DD-주제.md`).

## 현재 상태
- 옵시디언 보관함 Daily stocks(PC OneDrive\문서\Daily stocks)를 새로 만들었고 11/02 급등 42종목을 입력했다. Syncthing으로 안드로이드 폰(Documents/woong_stocks)과 동기화 중. 형식: [[일지-형식]]. 최근 기록: [[2026-11-03-옵시디언-일지-구축]]
- 11/03 급등 17종목도 입력했다 (종목 노트 59개, 테마 노트 17개). 기록: [[2026-11-03-11월3일-일지-입력]]

## 다음 할 일
1. 폰에서 일지·테마 트리 모양 확인 (고친 뒤 미확인, 11/03 포함).
2. 테마 없는 종목(11/02 약 20개 + 11/03 12개)에 사용자가 테마 입력.
3. PC 재부팅 대비: Syncthing 시작 프로그램 등록 (사용자가 직접).
4. (원하면) 텔레그램 글 → 일지 줄 변환 스크립트.

## 이 폴더 안
- `Sessions/` — 날짜별 일지 요약 (열 때 읽음)
- `Archive/` — 일지 상세 (필요할 때만 읽음)
- `docs/` — 상세 문서
- `code/` — 코드 조각·SQL
