# 2026-11-04 Daily — Surge CSV → 일지 스크립트

`일지/종목/테마` 폴더를 비운 뒤, Surge 가 만든 날짜별 CSV 를 읽어 일지·종목 노트를 만드는 스크립트 `csv_to_daily.py` 를 짜서 11/02·11/03 을 새로 만들었다. 테마·이슈·기사는 사용자가 직접 채운다.

- Surge CSV(`C:\Users\Jinwo\Documents\surge\2026년 11월 2일.csv`, `…3일.csv`; 열: date, code, name, pct, amount_est)를 읽는 스크립트 `C:\Users\Jinwo\Documents\surge\csv_to_daily.py` 작성. 사본: `Projects/Daily/code/csv_to_daily.py`.
- 임시 보관함으로 시험(실행, 두 번 실행 시 중복 없음, 사용자가 쓴 줄 보존, 파일은 BOM 없는 UTF-8) 후 실제 보관함에 실행: 일지 2개(11/02 48줄, 11/03 21줄), 종목 노트 66개, `테마/Null.md`.

## 결정 (이유)
- **줄 형식**: `- [[Null]] || [[종목(코드)]] +00.00%<br><br>` — 테마는 사용자가 직접 넣고, 첫 `<br>` 뒤에 이슈, 두 번째 `<br>` 뒤에 관련 기사. 사용자가 이 형식을 지정함 ("Null II" 는 `||` 로 해석).
- **덮어쓰지 않는다**: 이미 있는 일지는 없는 종목 줄만 아래에 붙이고, 이미 있는 종목·테마 노트는 건드리지 않음. 직접 쓴 내용이 지워지지 않게.
- **`amount_est`(거래대금)는 줄에 넣지 않음**: 사용자가 요청하지 않음.
- **스크립트는 Surge 폴더에 둠**: CSV 와 같은 폴더(`Documents\surge`)에 두라고 사용자가 지정. 스크립트가 있는 폴더에서 CSV 를 찾으므로 `surge_daily.py` 가 만든 다음 날 CSV 도 그대로 쓸 수 있음.

## 미해결·주의
- **일지 11/02·11/03 의 내용이 바뀌었다.** 전에 직접 쓴 것(11/02 42종목, 11/03 17종목, 테마·이슈 포함)은 휴지통에 있고, 지금 일지는 Surge CSV 기준(48줄, 21줄)이며 테마·이슈는 비어 있다. 종목 수가 다른 이유(Surge 가 전일 종가 대비 10%↑ 기준)는 Surge 쪽에서 아직 정하는 중.
- **"비웠는데 옵시디언에 자료가 보인다"는 문제**: 디스크는 비어 있었다. 원인(화면 갱신 / 다른 보관함 / Sync 원격에 자료 남음 / 폰) 미확인. 옵시디언 보관함 목록 파일은 아직 옛 경로를 가리킴.
- 옵시디언 화면에서 새 일지가 제대로 보이는지는 **확인하지 못함**.
- 일지 만들기(일일 노트·템플릿 삽입)가 안 되던 문제는 증상을 못 들어 그대로. 이 스크립트는 그 문제를 우회함(오늘 이후 날짜는 CSV 가 있으면 스크립트로 만들 수 있음).
