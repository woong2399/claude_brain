## 결정 (이유)
- **폴더 중첩 대신 링크**: 한 종목이 여러 테마에 속하기 때문.
- **이슈 노트 개별 → 일지 1개에 줄로 모으기**: 하루 20~30개면 노트가 너무 많아져서.
- **표 → 한 줄 목록**: 사용자가 표와 등락률 배지를 싫어함 (가독성).
- **테마는 원문에 "○○ 테마"라고 적힌 것만** 연결, 나머지는 사용자가 직접 입력 (임의로 넣지 말라고 지시).
- **등락은 `[등락:: n]`, 사유는 `(사유:: …)`**: 폰에서 순서 기반 CSS가 깨져서 괄호 모양으로 구분.
- **동기화는 Syncthing**: 무료, 폴더 그대로 동기화.

## 미해결·주의
- **PC 재부팅 시 Syncthing이 꺼짐**: 시작 프로그램 등록이 권한 확인에서 막힘. 사용자가 `shell:startup`에 바로가기를 넣어야 함 (미확인: 넣었는지).
- Templater "새 파일 생성 시 자동 실행"은 꺼져 있음 (위험 확인 체크는 사용자가 직접).
- 폰과 PC에서 같은 일지를 동시에 고치면 `sync-conflict` 파일이 생길 수 있음.
- 폰 화면 디자인(사유 색, 다크 모드)은 고친 뒤 **폰에서 확인하지 못함** (미확인).
- 사용자가 일지 수동 편집 중 HLB 그룹주 테마를 추가함. HLB테라퓨틱스 줄은 테마 미지정.
