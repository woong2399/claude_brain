# 2026-11-04 Daily — 시트 + 텔레그램 → 일지

## 한 줄 요약
사용자가 시트에 테마·뉴스 헤드라인·링크를 채우고 텔레그램 글을 붙여 주면, Claude 가 시트를 읽어 **종목 → 뉴스 → 텔레그램** 순서의 옵시디언 일지로 바꾸는 흐름을 만들었다. 11/02(55줄)·11/03(21줄)에 적용했다.

## 한 일
- 사용자가 "주식이 왜 오르는지 아직 지식이 부족해서 텔레그램을 참고하려 한다"고 설명 → 시트 열 구성과 일지 모양을 추천 (뉴스 헤드라인·링크는 직접 찾고, 텔레그램 사유는 원문 그대로).
- 사용자가 11/02·11/03 텔레그램 글을 붙여 줌. 시트에 **`H열 텔레그램`** 을 새로 만들어 11/02(H2:H56)·11/03(H58:H78)에 종목 코드로 맞춰 넣음 (기존 칸은 건드리지 않음).
- 스크립트 `Projects/Daily/code/sheet_to_journal.py` 작성: 시트 값(JSON)과 텔레그램 글(txt)을 합쳐 하루치 일지를 만들고, 없는 종목·테마 노트도 만든다. 시험 실행(`--dry-run` 같은 기본)과 `--apply` 가 있다. 적용 전 기존 일지를 백업.
- 옵시디언 11/02(55줄)·11/03(21줄) 일지를 새 형식으로 다시 씀. 종목 노트 +7(73개), 테마 노트 +14(15개).

## 결정 (이유)
- **줄 형식 (확정)**: 사용자가 순서를 "종목 / 뉴스 / 텔레그램"으로 지정.
  ```
  - [[테마]] || [[종목(코드)]] +00.00%<br>  뉴스: [헤드라인](링크)<br>  텔레그램: 원문
  ```
  - **링크는 지저분하게 안 보이게**: `[헤드라인](링크)` 로 쓰고 주소 뒤의 `utm_…` 추적 값은 지움.
  - **들여쓰기**: 뉴스·텔레그램 줄 앞에 em 공백(U+2003) 두 칸. 일반 공백은 화면에서 합쳐져 사라지고, `&emsp;` 는 소스에 글자가 노출되므로.
  - **비어 있는 종목도 두 칸 유지**: 뉴스·텔레그램이 없어도 `뉴스: `, `텔레그램: ` 칸을 남겨 바로 입력하게 함.
- **텔레그램은 원문 그대로 붙여 넣는다** (Claude 는 텔레그램을 읽을 수 없음). 사용자가 글을 붙여 주면 코드로 맞춰 시트 H열과 일지에 넣는다.
- **텔레그램 열은 맨 끝(H)**: 사용자가 이미 채운 F·G 칸이 밀리지 않게.
- **시트 셀은 고치지 않는다**: 코드의 앞자리 0 보정 등은 일지를 만들 때만 적용하고, 사용자가 쓴 칸은 바꾸지 않고 문제만 보고.
- **일지 덮어쓰기는 직접 고친 줄이 없을 때만**: 적용 전에 현재 일지와 직전 생성본을 비교했고, 달랐던 한 줄(사용자가 공백으로 들여쓰기를 시험한 11/02 큐리오시스)은 공백만 달라 그대로 덮어씀.

## 결과물
- 시트 `Daily 일지 입력` (주소는 [[2026-11-04-구글시트-일지입력]]). 열: 날짜·코드·종목·등락률(%)·테마·이슈(헤드라인)·뉴스링크·**텔레그램**.
- 스크립트 `Projects/Daily/code/sheet_to_journal.py` (입력 파일 `telegram_MMDD.txt`, `sheet_MMDD.json` 은 스크립트와 같은 폴더에 두는 방식. 지금은 이 세션 임시 폴더에서 돌렸고, 임시 폴더의 입력 파일은 저장소에 복사하지 않음).

## 미해결·주의
- **옵시디언 화면에서 확인 못 함**: 들여쓰기가 실제로 들여쓰기로 보이는지, 링크 문구만 보이는지, 노트 안 검색 블록(종목·테마 노트)에서 `<br>`·em 공백이 어떻게 보이는지.
- **11/02 시트에서 사용자가 아직 못 고친 것**: 더블유씨피 테마 오타 `전력저자장치(ESS)`(→ 옵시디언에 잘못된 테마 노트 `테마/전력저자장치(ESS).md` 가 생겨 있음), 한진칼우에 들어간 테마 `조선기자재, 피팅(관이음쇠) · 밸브`(성광벤드 칸이 한 줄 밀린 것으로 추정), 테마 칸이 빈 8종목(한국철강·성광벤드·태양금속·니어스랩·한화오션·아시아나항공·대한해운·한화엔진). 일지에는 시트에 적힌 대로만 들어가고 임의로 넣지 않음.
- **11/03 시트의 테마·뉴스·링크는 아직 비어 있음** → 일지에 전부 `[[Null]]`, 뉴스 칸은 비어 있음. 텔레그램이 테마를 언급한 종목: 한싹·파수AI·에스투더블유(보안주(정보)), 진양폴리(정치/인맥(오세훈)).
- **시트에 없는 종목**: 11/02 텔레그램의 영광(359410, +26.47%)·씨케이솔루션(480370, +10.16%), 11/03 텔레그램의 삼기에너지솔루션즈·대한유화·페스카로·현대그린푸드(모두 10% 미만). Surge CSV 에도 없음. 시트에 행을 넣을지 미정.
- **11/02 하단 7행(니어스랩 등)**: 사용자가 텔레그램에서 직접 넣은 종목이며 등락률 칸이 비고 코드 앞자리 0 이 빠져 있음 → 일지에서는 보정해서 씀(시트는 그대로).
- **덮어쓰기 규칙 미정**: 시트 → 일지로 다시 돌릴 때 옵시디언에서 직접 고친 줄을 덮어쓸지는 사용자가 정하지 않음. 지금은 직접 고친 줄이 있는지 사람이 먼저 비교함.
- **`csv_to_daily.py` 는 옛 모양(`<br><br>`)의 줄을 만든다.** 새 형식(뉴스·텔레그램 칸, 들여쓰기)과 맞추지 않았음.
- 옵시디언 Sync 가 켜져 있으면 이 변경이 원격에 올라가는지(폰 반영)는 미확인. 이전 기록의 미해결 항목(폰 Sync, Remotely Save 끄기, 일지 만들기 안 되는 증상)도 그대로.
