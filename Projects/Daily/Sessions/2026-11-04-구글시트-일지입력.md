# 2026-11-04 Daily — 구글 시트로 입력

## 한 줄 요약
옵시디언에 텍스트로 쓰기가 너무 번거로워서, **구글 시트에 이슈·뉴스링크를 입력하고 Claude 가 그것을 옵시디언 일지로 옮기는** 방식을 정했다. Google Sheets·Google Drive 커넥터를 연결하고, Surge 69종목을 담은 시트를 만들었다. 시트 → 일지 옮기는 부분은 아직 안 만들었다.

## 한 일
- 구글 시트 커넥터(Google Sheets, Google Drive)를 사용자가 연결 (이 세션에서 도구가 보임).
- 시트 `Daily 일지 입력` 생성: https://docs.google.com/spreadsheets/d/1FP57t2xz7VEkI7pODlmGxUi_yrdvXpnzc9iFE-H3Prw/edit (소유자 사용자 계정, 공유 설정 안 바꿈. 탭 이름 `시트1`).
- 열: `날짜` · `코드` · `종목` · `등락률(%)` · `테마` · `이슈` · `뉴스링크`. 앞 4열은 Surge CSV(11/02 48행, 11/03 21행, 합계 69행)에서 채움. 최신 날짜가 위, 같은 날은 등락률 높은 순. 뒤 3열은 사용자가 입력.
- 69행을 다시 읽어 확인: 코드 앞자리 0(`004545`)과 영문 섞인 코드(`18064K`, `0053F0`)가 그대로. 사용자가 "시트는 잘 왔어"라고 확인.

## 결정 (이유)
- **시트를 입력 화면으로 쓴다**: 옵시디언에 `||`, `<br>`, 링크 문법을 직접 타이핑하는 게 번거로워서. 폰에서도 시트가 쓰기 쉬움.
- **코드는 글자로 넣는다(앞에 `'`)**: 시트가 입력을 숫자로 바꿔 `004545` 가 `4545` 로 앞자리 0 이 사라지기 때문.
- **웹에 게시한 CSV 주소로 읽는 방법은 쓰지 않음**: 주소를 아는 사람 누구나 볼 수 있어 일지 내용이 공개되기 때문.
- **테마 열도 시트에 둔다**: 쉼표로 여러 개(`반도체, 조선`), 비면 `[[Null]]`. 사용자가 반대하지 않아 넣었으나 명시적으로 확인받지는 않음.

## 결과물
- 구글 시트 `Daily 일지 입력` (위 주소). 이 저장소에는 시트 내용을 복사하지 않음.

## 미해결·주의
- **시트 → 옵시디언 일지 옮기기는 아직 안 만들었다.** 시트가 채워진 뒤 Claude 가 시트를 읽어(Google Sheets 커넥터) 일지 줄로 바꾼다.
- **미정**: 시트에서 옮길 때 옵시디언에 이미 있는 줄을 시트 내용으로 덮어쓸지(옵시디언에서 직접 고친 내용이 사라짐), 건너뛸지. 사용자 답 아직 없음.
- **미정**: 뉴스 링크를 줄에서 `[기사](주소)` 로 보일지 (제안만 했고 확인 안 됨). 줄 형식 예: `- [[반도체]] || [[워트(396470)]] +29.92%<br>이슈<br>[기사](주소)`.
- 새 날짜가 생기면 그 날짜의 행을 시트 아래에 어떻게 붙일지(CSV 가 생길 때마다 Claude 가 이어 붙이는 방식 제안) 아직 확정 안 됨.
- 옵시디언 화면과 폰에서 일지가 제대로 보이는지는 여전히 **확인하지 못함**.

## 다음 할 일
1. 사용자가 시트의 `테마`·`이슈`·`뉴스링크` 를 채운다.
2. 덮어쓰기/건너뛰기, 뉴스 링크 모양을 정하고, 시트 → 일지 옮기기를 만들어 시험 후 실제 실행.
3. 새 날짜 CSV 가 생기면 시트에 행을 이어 붙인다.
4. 이전 기록의 다음 할 일 유지 (폰 Sync, Remotely Save 끄기, 일지 만들기 증상 등: [[2026-11-04-surge-csv-일지입력]]).
