# woong_stock

## 한 줄 설명
키움 REST API 로 코스피·코스닥 2,673종목의 일봉·분봉을 모아 DuckDB 에 쌓고, 급등 패턴·매수 근거를 백테스트로 찾는 프로젝트.

## 현재 상태 (2026-11-03)
- **자동 운영 중:** 평일 20:20 BIOS 켜짐 → 20:30 수집 → MotherDuck 업로드 → 월말 G 드라이브 백업 → 텔레그램 알림 → PC 종료. 주말 20:40 종료.
- **클라우드:** MotherDuck `woong_stock` DB (daily 약 1,237만 행, stocks, kiwoom_mktcap(11-02부터), krx_daily(비어 있음)). Colab `notebooks/simulate.ipynb` 로 시뮬레이션.
- **연구 결론:** 조건 캔들만으로 사면 손해(기준 성공률 8.5%, 32개 매매 조합 모두 평균 손실). "이미 강하게 움직이는 종목의 캔들"이 낫다 (52주 신고가, 240일선 대비 +60% 등, lift 1.25~1.5). 조합 최고 lift 약 2.0.
- 다음날 종가가 조건 캔들 시가 아래면 이후 실패율 91% → **손절 규칙**으로 쓴다.
