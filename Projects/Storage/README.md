# Storage (주식 수집, 저장소 이름: woong_stock)

## 한 줄 설명
키움 REST API 로 코스피·코스닥 2,673종목의 일봉·분봉을 모아 DuckDB 에 쌓는 프로젝트. (시뮬레이션·매수 근거 연구 기록은 2026-11-03 에 이 폴더에서 지웠다. 필요하면 git 기록에서 되살린다.)

## 현재 상태 (2026-11-03)
- **수집 방식 바꾸는 중 (11-03):** 평일 **16:00 정규장**(`run_update.bat 1600`) + **21:00 애프터마켓까지**(`run_update.bat 2100`, 월말 백업 포함), **PC 는 끄지 않음.** 코드는 고쳤고 11-03 에 1600·2100 을 손으로 한 번씩 돌려 둘 다 실패 0 으로 확인했다. 작업 스케줄러 4개(새 2개·예전 2개)는 **모두 꺼 둠 → 지금은 자동 수집 없음, 손으로 돌린다.** 같은 날 같은 이름(1600/2100)은 다시 돌려도 0종목을 받고 끝난다. → [[2026-11-03-수집방식변경]]
- **검증:** 거래정지로 보이는 종목(키움 상태 '거래정지' 또는 현재가 0)의 빠진 날은 검증 문제에서 빼고 알림에 따로 적는다 (11-03, 004415 서울식품우 계기).
- 예전 방식(꺼 둠): 평일 20:20 BIOS 켜짐 → 20:30 수집 → 업로드 → 월말 백업 → PC 종료. 주말 20:40 종료.
- **클라우드:** MotherDuck `woong_stock` DB (daily 약 1,237만 행, stocks, kiwoom_mktcap(11-02부터), krx_daily(비어 있음)).

## 꼭 지킬 것
- KRX 정보데이터시스템 자동 대량 조회 금지 (IP 차단 이력). 공식 Open API 만.
- MotherDuck 은 조회만. 같은 계정 `stocks` DB(매매일지)는 건드리지 않는다.
- 거래대금은 2005년 이후만, 분석은 2015-06 이후 (가격제한폭 ±15% 시절 제외).
