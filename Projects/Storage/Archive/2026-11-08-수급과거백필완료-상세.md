1. "커밋·push" → 저장소 `woong2399/storage` 에 `490659d` (after_update.ps1, dashboard.py·html, test_dashboard.py).
2. 사용자: "백필 할 게 남았던 것 같은데" → 프로그램 매매 과거(약 67,000호출·6.5시간 추정), 투자자별·외국인 보유 과거를 정리. "어떤 건 오래 걸려서 주말에 몰아 받아야 했던 것 같은데" → 합계 약 14시간(공매도·대차 제외)이라 제시. "지금 백필 돌리자".
3. 대시보드(DB 읽기)를 끄고 `/tmp/bf.sh` 로 체인 시작: investor → foreign → program, 모두 `--since`/`--start 2021-12-01`.
4. 사용자 "공매도 대차는 왜 안 넣어?" → 시간을 재 본 적이 없어 빠뜨린 것이라 답하고 추가. 체인을 끄고 순서를 investor → foreign → short → loan → program 으로 바꿔 다시 시작.
5. 사용자 "넣어"(위와 같은 요청이 다시 도착).
6. 10:06 에 진행 확인(외국인 1,300/2,674, 100종목당 약 14분). 이후 11-08 04:14 완료.
7. 사용자: "기록하고 대시보드 맡고(띄우고) 어떤 컬럼을 수집 중인지 영어 : 한국어로 나열" → 이 기록, 대시보드 재시작, [[Storage-수집-컬럼]].

## 시행착오
- 체인을 중간에 끊을 때 `TaskStop` 만으로는 이미 시작된 파이썬 자식 프로세스가 남아 다음 단계(foreign)로 계속 진행됐다. PowerShell `Get-CimInstance Win32_Process` 로 `-m storage` 명령행을 찾아 직접 종료한 뒤 다시 시작했다. 이어받기가 되는 작업이라 데이터 손실은 없다.
- 백필 중 DB 를 쓰는 프로그램은 하나뿐이므로 대시보드를 먼저 종료했다.

## 실행 명령

```
python -m storage flow --since 2021-12-01 --only investor|foreign|short|loan
python -m storage program --start 2021-12-01
```
