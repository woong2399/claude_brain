# 2026-11-04 Storage — KRX 시총 2010-01 까지 확장

상세: [[2026-11-04-KRX백필-2010확장-상세]] · 앞선 작업: [[2026-11-04-KRX백필-추정거래대금]]

## 한 줄 요약
KRX Open API 가 주는 **가장 먼 과거는 2010-01-04** 이고, `krx_daily` 를 **2010-01-04 ~ 2026-11-03, 거래일 4,143일, 933만 6,965행**으로 채웠다. 실패 0, 빈 값 0. 중간에 KRX 의 빈 응답 때문에 백필이 한 번 멈춰서 코드를 고쳤다.

## 한 일
- **시작일 탐색:** 우리 DB 달력으로 이진 탐색(호출 15건) → 2009-12-30 은 데이터 없음, **2010-01-04 부터 있음**. 2010 이전은 받을 수 없다.
- **백필:** `python -m storage backfill-krx --start 2010-01-01` (이미 받은 2015-06 이후는 건너뜀). 대상 2010-01-04 ~ 2015-05-29 거래일 1,339일(호출 2,678건).
  - 1차 10:08 시작, 10:37 에 `JSONDecodeError` 로 멈춤 (781일 저장).
  - 코드 수정 후 이어받기: 558일, 호출 1,116건, 약 12분, 실패 0.
- **오류 원인과 수정:** KRX 가 어느 날짜에 **JSON 이 아닌 빈 응답(200)** 을 줬는데 코드가 이를 처리하지 못해 전체가 종료됐다 (2015-06 이후 백필에는 없던 응답이라 놓침). 이제 JSON 이 아니면 서버 오류처럼 3번(2·4초 간격) 재시도하고, 계속 그러면 그 날짜만 실패로 기록하고 **전체는 계속**한다. 테스트 2개 추가, 전체 105개 통과.
- **결과 검증:** `krx_daily` 4,143일(2010-01-04~2026-11-03)이 DB 달력의 같은 기간 거래일 수(4,143)와 같다. 유가증권 3,817,319행·코스닥 5,519,646행, 종목코드 3,699개. 시가총액·거래대금·종가가 빈 행 0, 수집 기록 `done` 4,143·`failed` 0.
  - 삼성전자 시가총액: 2010-01-04 119.2조 원(종가 809,000), 2015-05-29 192.5조 원, 2015-06-01 190.2조 원 (종가는 원주가, 액면분할 전 값).
- **상장폐지 종목:** `stocks` 에 없는 코드가 1,024개이고 그중 **921개는 마지막 날이 2026-10 이전**(상장폐지 등으로 보임). 지금 DB 에 없는 종목의 종가·거래량·거래대금·시총 기록이다.

## 결정 (이유)
- **가능한 가장 먼 과거(2010-01-04)까지:** 사용자 결정. 시가총액이 있어야 "거래대금 ÷ 시가총액"을 2010년부터 볼 수 있다. 분석 기준은 여전히 2015-06 이후이지만 더 긴 기간이 필요할 때를 위해 받아 둔다.
- **탐색은 이진 탐색으로:** 없는 날을 돌리면 빈 응답이 실패로 쌓이고 호출만 낭비된다.
- **오류가 나도 전체를 멈추지 않는다:** 날짜 하나의 서버 문제 때문에 수천 건 작업이 끝나면 안 된다. 실패한 날만 기록하고 다음 실행에서 다시 받는다.
