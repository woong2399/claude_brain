# 2026-11-05 News — 기획

상세: [[2026-11-05-기획-상세]]

## 한 줄 요약
종목 짜깁기 공부를 벗어나려고 뉴스·공시를 먼저 모으는 News 프로젝트를 기획했다. 2단계까지(국내 매체 → DART 공시)로 범위를 정하고, 매체별 수집 방법과 폴더·DB 구조를 잡았다. 코드는 아직 없다.

## 한 일
- 뉴스 수집은 매체마다 API 가 필요하지 않고 **RSS 가 기본**이라는 점을 정리했다.
- 5개 매체 + 연합뉴스·머니투데이의 RSS 를 직접 받아 확인했다 → [[Projects/Assistant/News/docs/수집-설계]].
- `news` 폴더(`Documents\news`, 비어 있음)와 볼트의 역할을 나눴다.
- 폴더 구조, DB 테이블, 단계(1~4)를 설계했다.

## 결정 (이유)
- 기사 원본은 SQLite, 볼트엔 요약·공부 노트만 — 기사가 많아서 볼트가 무거워진다.
- 범위는 2단계까지 — 사용자 요청.
- 매일경제는 네이버 검색 API — RSS 가 Cloudflare 로 막혀 있고, 봇 차단은 우회하지 않는다. 구글 뉴스는 사용자가 잘 안 쓴다.
- 기사에 종목을 붙이는 건 나중 — 종목부터 끼워 맞추는 기존 방식을 피하려고.
- 옵시디언으로 기사 보기는 나중에.
