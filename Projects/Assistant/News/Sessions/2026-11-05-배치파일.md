# 2026-11-05 News — 배치파일

상세: [[2026-11-05-배치파일-상세]] · 앞: [[2026-11-05-한경수집]]

## 한 줄 요약
수집 과정을 한 번에 돌리는 `run_news.py` 와 더블클릭용 `run_news.bat` 을 만들었다. 실행하면 날짜를 묻고, 새로 받을 기사 수·예상 시간을 보여 준 뒤 수집 → DB → CSV → 구글 시트 순으로 저장한다. 시트 저장은 코드만 있고 **설정은 나중에** 하기로 했다.

## 한 일
- `run_news.py`: 시작·끝 날짜 입력(형식 자유, 미래 날짜 거절), 날짜별 신규 건수와 예상 시간 확인 후 `Y/n`, 실패분 1회 재시도, CSV 저장, 시트 저장.
- `run_news.bat`: UTF-8 설정 후 `run_news.py` 실행, 끝나도 창이 안 닫힘.
- `sheets.py` + `apps_script.gs`: 구글 시트에 붙이는 Apps Script 웹앱에 기사 행을 보내 덧붙인다(링크가 이미 있으면 건너뜀). `.env.example`, `README.md` 도 작성.
- 한경 평일/주말 건수 비교: 평일 350~450건대, 토 71건, 일 179건.

## 결정 (이유)
- 시트 저장은 **Apps Script 웹앱 방식**. 구글 클라우드 설정·추가 설치 없이 파이썬 기본 기능만 쓰려고. 대신 시트 쪽에서 사용자가 한 번 설정해야 한다.
- 시트 탭은 **`hankyung` 하나에 날짜 순으로 덧붙임**(날짜 열로 거름). 중복은 링크(G열)로 막는다.
- 비밀값(토큰, 웹앱 주소)은 `news\.env` 와 Apps Script 속성에만 둔다. 볼트·채팅에는 적지 않는다.
- 시트 설정은 **나중에**(사용자). 그 전에는 CSV 를 시트에서 `파일 → 가져오기` 로 올릴 수 있다.

## 미해결·주의
- **실제 구글 시트에 올라가는지 미확인.** Apps Script 설정을 안 했다. 사용자가 시트의 "확장 프로그램 → Apps Script" 를 누르니 드라이브 쪽으로 넘어가 열리지 않았다(정확한 화면 미확인). 그래서 `script.google.com` 에서 새 프로젝트로 만들고 `SHEET_ID` 속성을 넣는 방식도 지원하도록 코드를 고쳤다.
