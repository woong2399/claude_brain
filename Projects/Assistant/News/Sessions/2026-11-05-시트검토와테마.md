# 2026-11-05 News — 시트검토와테마

상세: [[2026-11-05-시트검토와테마-상세]] · 앞: [[2026-11-05-시트연결]]

## 한 줄 요약
시트의 11/01 한경 기사 179건에 "주식과 무관"을 X로 표시하고 이유를 적었다. 사용자가 J열에 단 의견 7건을 검토해 일부 X를 풀었다(76건 → 69건). 이어 11/01 기사의 반복 키워드와 테마 11개, 관련 업종·기업을 정리했다.

## 한 일
- 본문 읽기 가능 여부 확인: DB 에는 본문이 없다. 링크를 열면 본문 영역은 있으나 일부만 뽑혀 전체 확보는 미확인. "읽고 싶은 기사만 골라 정리"하는 방식을 제안.
- 시트 `hankyung` 탭에 H열(주식무관 X), I열(이유) 작성. 정치·외교·정책·지정학은 목표(세상 파악)에 필요할 수 있어 **분명히 무관한 것만 X**, 애매하면 비움.
- J열 사용자 의견 7건 검토, 기사 2건(84행 인사, 173행 정상 방한)은 직접 열어 확인 후 판단. 제안대로 수정.
- 11/01 기사 키워드 집계와 테마 11개 분류(아래 요약, 표는 상세 노트).

## 결정 (이유)
- **X 기준:** 사건사고·연예·문화·스포츠·부고·인사·칼럼·사진 기사, 개별 재판, 정당 내부 정치 등. 종목과 연결이 약하면 X.
- **사용자 의견 반영(2026-11-05):** 속보([속보])는 살린다(37·42행), 교정시설(119·152·153행)은 부동산·건설 연관 가능, 173행(튀르키예 정상회담, 원전·방산 의제)과 177행(해외 해킹→국내 보안)은 X 해제. 풀린 행은 이유를 "관찰 필요: …"로 바꿈. 56행(해커톤은 해킹이 아님)과 84행(지방 고위공무원 인사)은 X 유지.
- **테마 분석은 기사 제목·요약 기준.** 본문은 읽지 않았고, 관련주는 "기사에 직접 나온 기업"과 "일반적으로 거론되는 업종(기사 밖, 확인 필요)"을 나눠 적었다. 매수 추천이 아니다.

## 결과물
- 시트 `hankyung` 탭: H·I열(X 69건 추정, 시트에서 세어 보지는 않음), 회색 표시 조건부 서식, 사용자 J열 의견은 그대로.
- 분석은 파일로 저장하지 않았고 이 노트와 상세 노트에만 있다.

## 미해결·주의
- **시트에 쓸 때 행 수를 잘못 세서 109행 이후가 2칸 밀린 실수**가 있었다. 바로 고쳤고 제목과 X 표시를 전체 대조해 확인함. 긴 배열을 쓸 때는 구간을 나눠 행 번호로 맞추고 쓴 뒤 대조한다.
- X 표시와 테마는 시트에만 있고 `news.db` 에는 없다. 앞으로 새로 올리는 기사에는 H·I열이 비어 있다.
- 11/01 은 일요일 하루치(179건)라 반복 빈도가 작다. 평일(400건대)과 비교해야 의미가 커진다.
- 한경 179건이 전체인지, 사용자가 돌리던 수집이 끝났는지는 여전히 미확인.
