# 2026-11-05 News — 시트연결

상세: [[2026-11-05-시트연결-상세]] · 앞: [[2026-11-05-배치파일]]

## 한 줄 요약
미뤄 뒀던 구글 시트 설정을 끝냈다. Apps Script 웹앱을 배포하고 `.env` 에 주소·토큰을 넣었다. 11/01 로 시험하니 연결과 토큰은 정상이고 기존 179건은 중복으로 건너뛰었다. **새 날짜 기사를 실제로 덧붙이는 동작은 아직 미확인.**

## 한 일
- 사용자가 설정 중 토큰(비밀 문자열)을 잊어버림 → Claude 가 새 토큰을 만들어 `news\.env` 에 **값을 화면에 보이지 않게** 바로 넣음. 사용자는 `.env` 에서 복사해 Apps Script 속성 `TOKEN` 에 넣음.
- 사용자가 `script.google.com` 새 프로젝트로 `apps_script.gs` 를 붙이고 `SHEET_ID` 속성을 넣어 웹 앱으로 배포. "Google hasn't verified this app" 경고는 본인 스크립트라 나오는 것이라 `Advanced → Go to … (unsafe) → Allow` 로 진행.
- `.env` 에 `SHEETS_WEBAPP_URL`(웹앱 주소)을 넣음. 값은 Claude 가 보지 않고 형식과 설정 여부만 확인.
- `run_news.py --from 2026-11-01 --yes` 로 시험 → "0건 추가, 이미 있어서 건너뜀 179건".

## 결정 (이유)
- 새 토큰은 **Claude 가 만들어 `.env` 에 직접 씀**(채팅에 값을 보이지 않으려고). 토큰은 비밀번호 역할이라 잊으면 새로 만들고 `.env` 와 Apps Script 속성 두 곳을 같이 고치면 된다.
- 비밀값은 볼트에 적지 않는다. 위치만: `news\.env` 와 Apps Script 프로젝트 설정의 스크립트 속성 `TOKEN`.

## 결과물
- 연결 확인: 토큰 일치, 중복 방지(링크 기준) 동작.
- 시트는 건드린 것 없음(0건 추가).

## 미해결·주의
- **새 날짜를 실제로 덧붙이면 시트 모양(날짜·시각 칸이 글자로 들어가는지)이 괜찮은지 미확인.**
- 수집 프로그램(`run_news.py`)이 사용자 쪽에서 오후 1시 39분부터 돌고 있었다. 끝나기 전에 같은 프로그램을 또 실행하면 DB 가 잠겨(database is locked) 일부 기사가 실패할 수 있다(다시 돌리면 채워짐). 이 수집이 어느 날짜였고 끝났는지, 시트에 올라갔는지는 미확인.
- 한경 11/01 179건이 한경이 낸 전체인지는 여전히 미확인.
