# 2026-11-05 News — 자동검토

상세: [[2026-11-05-자동검토-상세]] · 앞: [[2026-11-05-시트검토와테마]]

## 한 줄 요약
시트에 빠져 있던 11/02 기사 411건을 올리고 날짜 순으로 정렬했다. 이어 Claude 가 손으로 하던 "주식과 무관한 기사에 X·이유 달기"를 **규칙 코드로 1차 자동화**하고, 수집과 별개인 **뉴스 검토 배치파일**(`review_news.bat`)을 만들었다. Apps Script 를 새 버전으로 배포하고 `review_news.bat` 으로 11/02~11/04 를 돌린 뒤, **사용자가 "X 잘 달렸어"라고 확인**했다(시트에서 11/01 사람 표시는 그대로, 181~1486행에 X 가 달린 것 확인, 정확한 건수는 세지 않음).

## 한 일
- 시트에 11/02 누락 확인(11/01·11/03·11/04만 있었음, 원인: 11/02 수집·저장이 시트 설정 전에 끝남). `run_news.py` 로 411건 추가 후 181~1486행을 날짜·시각 순으로 정렬(11/01 179 / 11/02 411 / 11/03 445 / 11/04 450). H~J열은 181행 이후 비어 있음을 확인하고 정렬.
- `classify.py`: 분류(section)와 제목 머리말로 "주식 무관" X 와 "자동: 이유" 판단. `[속보]`는 X 안 함, 주식·경제 단어가 있으면 X 안 함.
- `sheets.mark()` + `apps_script.gs` 의 `marks` 기능: H·I열이 비어 있는 **날짜**에만 자동 X 를 씀(사람이 검토한 날짜 보호). `run_news.py` 가 시트 저장 뒤 호출.
- `review_news.py` + `review_news.bat`: 날짜 지정 → (1) 시트 자동 X 표시 (2) `data\review\review-날짜.md` 에 반복 키워드·테마 요약. 수집은 안 함. `themes.py` 에 키워드·테마 집계.

## 결정 (이유)
- **X 달기는 규칙으로 1차, 애매한 건 Claude 가 검토**(사용자 선택 1번). 이유: 코드만으로는 내용을 읽는 판단을 못 하고, AI API 는 키·비용·설정이 필요해서. 이유 칸은 "자동:"으로 시작해 사람이 단 것과 구분.
- **"적절하지 않은 뉴스(주식 무관)에만 X"**(사용자 요청): 확실히 무관한 분류(부고·사건사고·스포츠·연예·여행·날씨·패션 등)만 X, 주식·경제 단어가 있으면 안 달아 틀리게 다는 쪽보다 덜 다는 쪽을 택함.
- 사용자가 살리기로 한 것(속보, 교정시설·해킹·원전·방산·정상회담)은 KEEP 규칙에 반영.
- 이미 H·I열에 값이 있는 날짜는 자동으로 덮어쓰지 않음(11/01 수작업 보호).
- 키워드 집계에서 **기자 이름**(요약 끝 "김희선 기자, 정치")을 뺌. 그대로 두면 `김희선`·`이수`가 반복 키워드로 잘못 잡힘.

## 미해결·주의
- Apps Script 새 버전 배포가 필요한 기능이다(코드 붙여 넣기 → 배포 관리 → 새 버전). 안 하면 시트 표시는 "새 버전으로 다시 배포해 주세요" 안내만 나오고 기사 저장·요약 파일은 정상. **배포 후 실제로 동작함을 사용자가 확인**(2026-11-05). 코드 문법 검사는 이 PC 에 `node` 가 없어 못 했지만 실제 배포·실행이 됐다.
- 시트의 11/02~11/04 자동 X 는 규칙 결과이며 사람이 검토한 것은 아니다. 규칙이 놓친 기사는 Claude 검토가 필요.
- 시트에 올리면 항상 맨 끝에 붙는다(날짜 순서로 돌리면 유지, 거꾸로면 섞임 → 정렬 필요).
- DB 에 11/05 기사 1건이 있으나 시트에는 안 올림.
- 테마·키워드는 단어 규칙 집계라 참고용, 관련 종목 판단은 포함하지 않음.
