# 2026-11-05 News — RSS전환

상세: [[2026-11-05-RSS전환-상세]] · 앞: [[2026-11-05-양질뉴스와목표]] · 목표: [[Knowledge/주식비서-목표와구조]]

## 한 줄 요약
사용자가 **"갈아엎는다, 뉴스 수집은 RSS 로만"** 으로 결정해 사이트맵 수집을 RSS 로 바꾸고 `news` 폴더를 정리했다. 자동 X 규칙(`classify.py`)을 RSS 용으로 새로 만들었고, 같은 사건 묶기·기사 종류 태그·미국 매체 수집을 붙였다. 수집은 **작업 스케줄러가 매시 정각·30분**에 돌린다.

## 한 일
- **RSS 수집기:** `src/feeds.py`(피드 목록) + `src/rss.py`. 한국 10개 매체 35개 피드, 미국 7개 매체. 한 번 돌면 약 1분. 링크가 같으면 한 번만 저장. 피드 하나가 실패해도 나머지는 계속.
- **폴더 정리(데이터 섞임 방지):** 코드는 `src/`, RSS 데이터는 `data/rss/`, 옛 사이트맵 데이터는 `data/legacy_sitemap/`, 옛 수집 코드는 `legacy/sitemap/`, Apps Script 는 `apps_script/`. 시트 탭도 RSS 는 `rss`(옛 것은 `hankyung`).
- **저장:** 기본은 DB + 날짜별 CSV(최근 3일만). 구글 시트는 `--sheet` 를 줄 때만(사용자: 일단 CSV 로 충분).
- **자동 실행:** 작업 `news-rss-collect`, **매시 정각·30분**(사용자 결정, 처음 30분 → 1시간 → 다시 30분). 창 없이 `pythonw`, 로그는 `data/rss/run.log`. 18:30 실행이 오류 없이 돌아 259건 추가 확인.
- **`classify.py` 새로 작성:** RSS 는 분류가 제각각이라 제목 중심. 옛 파일은 `legacy/old_rules/classify_sitemap.py` 로 보관(사용자가 "삭제"라고 했으나 git 커밋이 없어 되살릴 수 없어서 보관으로 바꿈, 알림). 11/05 2,835건 중 197건 X.
- **같은 사건 묶기(`cluster.py`, `events.py`):** 제목+요약 글자 2개 묶음 TF-IDF 코사인 0.30. 11/05 2,602건 중 약 1,300건이 334개 묶음. `events_news.bat`.
- **기사 종류 태그(`tags.py`, `tags_report.py`):** 실적·계약·인수합병·자본·임상·규제·공장투자·목표가(직접) + 정책·거시·시황·정치. 한국어는 사건별로 묶어 보고, 미국은 영어 태그.
- **미국 매체 추가:** CNBC 6개 피드, MarketWatch, NYT(경제·정치), 폴리티코, 연준, SEC, 시킹알파. 11/05 미국 기사 86건.
- **종목 직접 영향 기사 점검:** 키워드로 299건 → 약 165개 사건. 실적(카카오·SK바이오팜·LG화학·넷마블 등), 계약·인수(한화에어로 폴란드 공장, 삼성에피스홀딩스–테바 5,632억, 삼성바이오 공개매수), 목표가 조정, 임상, 업종 흐름(중간선거 후 삼전·하닉 급락, 유가 급락→항공주). 상세는 [[2026-11-05-RSS전환-상세]].

## 결정 (이유)
- **RSS 전용**(사용자): 자동·최신성 중심. 과거 날짜는 못 받는다는 점을 사용자가 확인함("과거도 되네!" → 피드에 남은 일부만이라고 정정).
- **수집 주기 30분:** 속보 피드(연합 약 1시간, 뉴시스 속보 약 0.7시간)가 그 안에 밀려나서.
- **한국어 규칙(X·묶기)은 미국 기사에 적용 안 함.** 미국은 태그 보고서에서만 본다.
- **CSV 는 최근 3일만.** 미국 피드에 몇 주 전 기사가 섞여 작은 옛 CSV 가 생겨서(사용자 요청으로 고침).
- 사용자: 이 세션에서는 **뉴스 수집에 집중**하고 이벤트 추출(실적 발표 일정·수치 등 사건 기록)은 보류.

## 미해결·주의
- **정확도는 모두 미확인:** 새 `classify.py`, 태그, 묶음 기준(0.30)은 표본을 눈으로 보고 고쳤을 뿐 정답 라벨 대조 없음. 큰 묶음에 다른 사건이 섞임(카카오 62건, 시황 중계 54건).
- **PC 가 꺼져 있으면 수집이 안 된다.** RSS 는 지난 시간을 되돌려 받을 수 없다. 켠 직후 한 번 따라잡기만 한다.
- **완전한 날짜는 11/06 부터.** 11/03·11/04 RSS 분은 일부만(옛 사이트맵 한경 분이 더 완전).
- `quality.py`·`themes.py`·`review_news` 는 사이트맵 시절 코드를 그대로 써서 RSS 데이터에서 동작은 하지만(양질 사건 10개) 기준 재검증 안 함.
- Apps Script 새 버전(`incremental` 표시)은 재배포 전. 시트 `rss` 탭은 아직 안 씀.
- `.env` 에 `DART_API_KEY` 가 들어 있다(사용자가 넣음). 값은 보지 않았고 쓰는 코드는 아직 없다.
- 이데일리·서울경제 RSS 없음, 한겨레 403, WSJ·로이터·AP 불가(미국). 매경 RSS 는 열려 우회 없이 사용.
