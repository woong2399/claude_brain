## 매일경제를 어떻게 할지
- 사용자가 "매경을 뚫는 방법"을 물었다. Cloudflare 확인 화면은 봇 차단 장치라서 우회(헤더 위조, 브라우저 자동화로 통과 등)는 하지 않겠다고 했다. 약관 문제도 있다.
- 대신 합법적인 길을 제시했다: 구글 뉴스 RSS(`site:mk.co.kr`), 네이버 검색 API, 매일경제에 문의.
- 구글 뉴스 RSS 를 시험해 봤다: `news.google.com/rss/search?q=site:mk.co.kr+when:1d&hl=ko&gl=KR&ceid=KR:ko` → 200, 100건, 출처 표시 "매일경제" 76·"m.mk.co.kr" 21·"stock.mk.co.kr" 3. 요약이 없고 "MK시그널"·골든크로스 종목·사진(MK포토) 같은 기사가 많았다.
- 사용자: "구글은 잘 안 쓰고 네이버 API 로 매경 가져오자." → 네이버 검색 API 로 확정.
- 네이버 API 의 한계를 알렸다: 검색어 필수, 매체 지정 불가, 전 매체 결과를 받아 `originallink` 가 `mk.co.kr` 인 것만 남겨야 하며, 키워드에 안 걸린 기사는 놓친다. 하루 25,000회, 한 번 100건. 키는 사용자가 발급해 `.env` 에 직접 적는다(Claude 는 키를 입력·발급하지 않는다).
