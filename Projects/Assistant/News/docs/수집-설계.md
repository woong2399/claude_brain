## 단계
1. 국내 매체 기사 수집 (RSS + 매일경제는 네이버 검색 API) → SQLite
2. DART 공시 수집 (공급계약 등)
3. (미룸) 주제 분류, 일일 요약 "오늘 세상에서 일어난 일 10가지", 미국 뉴스
4. (미룸) 요약을 옵시디언으로 내보내기, 주가 반응 검증, 종목 연결

## 네이버 뉴스 검색 API (매일경제용)
- **검색어가 필수.** 매체만 지정해 목록을 받을 수 없다. 전 매체 결과가 섞여 오므로 원문 주소(`originallink`)가 `mk.co.kr` 인 것만 남긴다.
- 한 번에 100건, `sort=date`, 하루 25,000회 무료. 받는 칸: 제목·요약·링크·시각 (본문 없음).
- 키워드에 안 걸린 기사는 놓칠 수 있다 (RSS 보다 약함). 키워드는 `sources.yaml` 에 두고 고친다.
- 키워드 묶음 안: 금리·환율·물가·증시 / 정부 정책·규제·국회·예산 / 선거·관세·미국 / 공급계약·수주·인수합병 (**초안, 미확정**)
- 키 발급: 네이버 개발자센터에서 애플리케이션 등록 → 사용 API "검색" → WEB 설정 `http://localhost` → Client ID·Secret 을 `news\.env` 에 사용자가 직접 적는다.

## 공시 (DART OpenAPI)
- 무료 키 (opendart.fss.or.kr), 하루 약 20,000건. 공시 목록에서 보고서명으로 "단일판매·공급계약" 등을 거르고, 금액·상대방은 본문 조회로 확인 (이 부분은 구현 때 확인 필요, 미확인).

## 주의
- 구글 뉴스 RSS(`site:mk.co.kr`) 는 매일경제가 100건 들어오는 걸 확인했으나 사용자가 구글을 안 써서 안 쓴다. 그 결과엔 "MK시그널", 종목 추천성 기사, 사진 기사가 많이 섞여 있었다 → 네이버 결과에도 **수집 후 거르는 규칙**이 필요할 수 있다.
- 같은 사건을 매체마다 다루므로 제목이 비슷한 기사 묶기가 나중에 필요할 수 있다.
