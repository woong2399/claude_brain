## 붙여 넣은 이전 대화의 내용
- 이름 추천: `Surge`(급등). 후보 `Up10`(기준이 이름에 드러남), `Screen`, `Pick`.
- 폴더 구성: README / docs / code / Sessions / Archive (`CLAUDE.md` 다섯 칸).
- 볼트에는 정의·SQL·건수·연도별 통계 같은 요약만. 10%↑ 날을 모두 세면 수만~수십만 행이라 폰 동기화가 무거워짐.
- 작업 방식: `woong_stock.daily` 조회만(정규장 수정주가·종가) → 종목별 `close / lag(close) - 1 >= 0.10` → CSV/xlsx 저장, 필요하면 별도 MotherDuck DB (기존 DB 에는 쓰지 않음) → 요약 기록.
- 먼저 정할 다섯 가지: 상승 기준 / 기간(2015-06 이후 vs 1985~ 전체) / 제외 규칙(거래정지 직후, 신규상장 첫날, 수정주가 변경일) / 필터(거래대금, 동전주) / 결과 형태(날짜별, 종목별 횟수, 둘 다).
- 마지막에 사용자가 "좋아 기다려" 라고 답한 상태에서 끊김.
