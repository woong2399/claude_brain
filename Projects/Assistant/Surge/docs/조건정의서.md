## 매일 실행 (2026-11-04 결정)
- Storage 가 평일 16:00(`storage_update_1600`)·21:00(`storage_update_2100`)에 수집한다. 정규장 일봉(`KRX_REG`)은 늦게 돌려도 같다.
- **16:00 수집이 끝나면 사용자가 "1600 끝났어"라고 알리고, Claude 가 `surge_daily.py` 를 돌린다.** 21:00 수집 뒤에는 돌리지 않는다.
- 명령: `C:\Users\Jinwo\Documents\storage\.venv\Scripts\python C:\Users\Jinwo\Documents\assistant\surge\surge_daily.py [YYYY-MM-DD]` — 날짜를 생략하면 오늘. 로컬 DuckDB 가 2.0 형식이라 `.venv-md` 가 아니라 **`.venv`** 로 돌린다.
- 동작: Storage 로컬 DB 를 읽기 전용으로 열고, 그날 `KRX_REG` 수정주가 일봉이 1,000행 이상 있을 때만 CSV 를 만든다. 같은 날을 다시 돌리면 CSV 를 덮어쓴다. 어디에도 쓰지 않는다. 종료 코드: 0 성공, 1 데이터 없음(수집 전·휴장일), 2 오류(DB 잠김 포함).

- Storage 의 `after_update.ps1` 은 고치지 않았다. 자동 연결은 첫 자동 수집이 정상인지 확인한 뒤에 정한다 (미정).
