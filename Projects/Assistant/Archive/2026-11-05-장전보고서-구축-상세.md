# 상세 — 장전 보고서 구축 (2026-11-05)

## 대화 흐름
1. "claude_brain 열어줘" → 프로젝트 5개 표시. 사용자가 "여기서는 assistant 를 만들 것, 기획부터" → 폴더 위치 질문, 이후 "claude_brain 전부 읽고 Projects 안에 assistant 추가". 읽은 범위는 인덱스·Knowledge·프로젝트 README·템플릿(세션/Archive/코드는 분량 때문에 안 읽음).
2. 보고서 기획: 사용자가 장전 8:00(1시간 전)·마감전 2:30(1시간 전) 보고서를 제안하고 내용 예시를 줬다. 마감전은 나중으로. 항목을 ①주요 지수 ②미국 지표·뉴스 ③전자공시 ④예정 행사 ⑤수급 테마로 정리.
3. 프로그램 매매: 사용자가 Storage 에 넣을 수 있는지, 지표가 되는지 질문. 답: 키움 API 에 있는 것으로 알지만 **미확인**(코드·문서에 투자자별 수급이 없음). 차익은 방향 정보 거의 없음, 비차익은 ETF·바스켓 영향, 종목별은 당일 주가와 같이 움직여도 다음 날 보장 없음 → 우리 데이터로 lift 로 재 보자고 제안. 수집 중이라 시험 호출 못 함.
4. 지표 소스: 야후/FRED/frankfurter 호출 시험 → 대부분 성공. 사용자가 investing.com 을 쓰자고 함 → 일반 요청이 403, 우회 안 함(사용자가 코드 주겠다고 했으나 거절). 야후 정확도 질문 → FRED 와 비교(아래).
5. 예정 행사: 마녀의 날 등 질문 → 규칙(둘째 목·셋째 금)과 고정 일정표로 구성. FOMC·CPI·고용지표·금통위·NYSE 휴장 날짜를 공식 사이트에서 확인.
6. 저장 위치: 사용자가 처음엔 MotherDuck + 대시보드를 원함 → DB·Dive 생성 → 로그인 차단·"streamlit 으로 만들어줘"(사용자는 이전 다른 세션에서 내가 제안했다고 기억, 이 세션 기록엔 없음) → 로컬 JSON + Streamlit 으로 전환.
7. 폰 접속: 방법 A(같은 와이파이)/B(Tailscale)/C(Streamlit Cloud+MotherDuck) 설명 → 사용자 "잘 모르겠어" → Tailscale 권장, 설치 안내, 사용자가 PC 의 Tailscale 주소 전달.
8. 화면 다듬기: 지수 카드 너무 큼 → 3열·작은 글자, 비트코인 제거, 행사/공시 들여쓰기 형식.
9. 공시: 사용자가 DART 키를 발급해 `news\.env` 에 넣음(40자리 확인) → 하루치 531건 조회 → 키워드 초안 → 사용자가 "계약, 주주환원, 리스크만" → 구현.

## 시행착오·버린 방법
- MotherDuck 업로드: duckdb 최신(2.0.0)이 MotherDuck 미지원 → **1.5.6 으로 고정**해서 해결.
- MotherDuck Dive(대시보드)와 `assistant` DB 를 만들었으나 사용자가 Streamlit 으로 전환하면서 쓰지 않게 됨.
- 첫 시험 서버를 `--server.address` 없이 띄워 외부 주소까지 열림 → 사용자가 직접 종료, 이후 Tailscale 주소로만 열게 고침.
- 행사 코드를 넣다가 f-string 줄바꿈이 깨져 화면 오류 → 문법 오류 수정, 이후 `AppTest` 로 화면 코드를 돌려 확인.
- 스케줄러(`assistant_report_0800`, `assistant_app`) 등록은 자동 권한 검사(Unauthorized Persistence)에서 거부 → 우회하지 않고 멈춤.
- 서버 프로세스 종료도 한 번 거부됨 → 사용자가 직접 종료.
