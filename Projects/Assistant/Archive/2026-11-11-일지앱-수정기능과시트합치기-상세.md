# 상세 — 2026-11-11

## 흐름
1. **Secrets 오류**: 클라우드에 키를 넣어도 "서비스 계정 키가 Secrets 에 없습니다". 원인: `st.cache_resource` 가 첫 실패(None)를 캐시. `_make_client` 가 예외를 던지고 `_client()` 가 감싸게 고침.
2. **주소**: 사용자가 `woong-daily` 로 변경. 전체 주소 `https://woong-daily.streamlit.app`.
3. **수정 기능 처음 설계**: 이슈·거래대금·종목·테마 어디서나 수정 → 사용자가 복잡하다고 해 **종목 화면에서만**(테마·거래대금 이유·관심종목 한줄평)으로 줄임. 텔레그램 글은 수정 불가.
4. **화면 손질**: 거래대금 화면 등락률순(기본)/테마별, 종목 카드의 "10% 상승 N번, 거래대금 30위 N번" 요약줄 삭제, 카드 간격 5px, 테마 화면의 숨은 테마 보이게, 회색 설명 글씨와 여백(스트림릿 markdown 컨테이너의 음수 마진) CSS 로 고침.
5. **아이콘**: 텔레그램 💬, 거래대금 이유 📌 (비행기 대신 메신저 대화 아이콘으로 정함).
6. **관심종목**: 처음엔 이름 기반 탭 → DB 종목(code)만 추가하도록 바꿈. 실제 탭은 옛 헤더라서 "추가했는데 비어 있음" → 탭을 새 형식(code,name,theme,comment)으로 이관하고 앱이 옛 탭을 자동 이관.
7. **비밀번호**: 쿠키는 클라우드에서 앱에 안 넘어옴(앱이 iframe `/~/+/page`). localStorage 에 HMAC-SHA256(비밀번호) 토큰을 저장하고 숨은 text_input 으로 서버에 전달.
8. **테마 입력**: 입력해도 저장이 안 되던 문제와 "No results" → multiselect `accept_new_options=True` + `on_change`. 오타 방지는 `theme_resolve`: 정확히 같음→기존 테마, 비슷(편집거리·접두)→"혹시 ~?"로 묻기, 아니면 새 테마.
9. **이전 화면 복귀**: 카드 링크에 `from=`·`day=`·`theme=` 를 달고, ✏️ 수정을 끄면 `st.switch_page(query_params=)` 로 돌아감. 이슈·거래대금은 `iss_day`/`vol_day`, 테마는 `thm_goto` 로 복원.
10. **시트 합치기**("진행해줘"): 백업 먼저(`surge\backup_sheets_2026-11-11\`). amount 시트로 `이력` 복사, `종목` 탭 병합(324개; 테마는 거래대금상위+이력에서 TEXTJOIN/UNIQUE/TOCOL 수식으로, info·memo 는 직접 입력값 유지), `테마`·`테마보기`는 amount 쪽 유지. 검증: 이력 362행 동일, 오류 없음. 옛 surge 시트 이름에 "(백업 …)" 붙임.
11. **테마 일괄 변경**: 처음엔 시트에서 찾기·바꾸기 안내 → "a로 만들자"(앱에서)로 결정. `edit.rename_preview`·`rename_theme`·`_final_name`·`_replace_tokens`. 쉼표로 나뉜 테마를 하나씩 정확히 비교(예: `반도체` 바꿔도 `반도체(장비)`·`메모리 반도체` 는 그대로), 겹치면 한 번만. 이력·거래대금상위·관심종목·테마목록 갱신.

## 시도했다 버린 것
- 모든 화면 수정 / 폼형 수정 UI / 큰 버튼 → 복잡해서 버림.
- 쿠키 기반 로그인 → 클라우드에서 불가.
- 시트 두 개를 서로 채우는 코드 → 시트를 합쳐서 제거.

## 시험 방식과 한계
- 임시 `_t.py` 로 `gspread.Spreadsheet.worksheet` 를 메모리 가짜 시트로 바꿔 시험(커밋 전 삭제). 테마 정리: `전력설비 · 변압기` → `전력기기 · 변압기` 합치기에서 5칸 변경, 옛 이름 사라짐, 새 이름 화면으로 이동까지 확인. 검증 메시지(빈 값·쉼표·null·그대로)도 확인.
- 진짜 시트에 쓰는 것, 비밀번호 로그인 후 저장은 미확인.
