# 상세 기록

## 대화의 흐름 (순서대로)
1. **동기화를 바꾸려 한다**: 사용자가 Remotely Save 플러그인으로 갈아타려 한다며 설명서와 클라우드 추천을 요청. 추천은 OneDrive(가입 쉬움) / Dropbox / R2·B2(설정 번거로움), Google Drive 는 유료(PRO) 기능이라 제외. 보관함이 OneDrive 폴더 안이면 OneDrive 클라이언트와 겹치므로 밖으로 옮기라고 안내.
2. **보관함이 이동돼 있었음**: 확인하니 옛 `OneDrive\문서\Daily stocks` 는 휴지통(23:05)으로 가고, 사용자가 `C:\Users\Jinwo\Documents\Obsidian\storage` 로 옮긴 뒤 곧 `Daily` 로 이름을 바꿨다고 정정. 내용(일지 2, 종목 59, 테마 17)은 그대로. Remotely Save 플러그인은 23:08 설치, 설정은 23:11 저장.
3. **"원격 보관함"의 정체**: 사용자가 설정 화면을 보여 줌 → 코어 **동기화(Obsidian Sync)** 가 "Jinwoong" 원격 보관함에 연결돼 실행 중(1.00GB 중 4.10MB). Remotely Save 설명서는 필요 없어짐. 나는 "Sync 하나만 쓰기"를 권함.
4. **Surge → Daily 가져오기, 폰용 형식**: 사용자가 Surge 에서 10%↑ 종목을 추려 Daily 에 기본만 채우고 테마·이슈는 직접 입력하고 싶다고, 또 폰에는 플러그인이 없으니 기본 옵시디언 기능만으로 되는 템플릿을 원한다고 함. Surge 기준은 다른 세션에서 정하기로(이 세션에서 만들지 않음).
5. **형식을 계속 바꿈** (아래 표).
6. **종목·테마 노트 안에 목록을 직접 보이게**: 백링크 패널을 열기 싫다고 해서 코어 검색 블록으로 교체. 이슈가 안 보인다고 해서 `<br>` 한 줄로 합침.
7. **화면에서 확인한 문제 둘**: (a) 소스 모드라서 `[[한싹|한싹(430690)]]` 가 이름이 두 번 보임 → 종목 노트 이름을 `종목(코드)` 로 변경. (b) 템플릿을 연 11/03 일지의 `날짜`가 `{"{ date:YYYY-MM-DD }":null}` 로 망가짐 → 아래 "실수".
8. **일지 만들기가 안 된다**: 일일 노트 열기 / 템플릿 삽입 / 복사 어느 것도 "안 된다"고 함. 일일 노트 설정 화면에서 "템플릿/일지 템플릿 — 파일을 찾을 수 없습니다" 경고 → 사용자가 화면에서 템플릿을 다시 골라 `템플릿/일지 템플릿.md` 로 저장됨. 구체적 증상은 끝내 못 들음. 화면을 보려 컴퓨터 사용 권한을 요청했으나 사용자가 거부.
9. 마지막 요구: **자동 생성이 아니라 직접 타이핑해서 쓸 수 있어야 한다.** 과거 날짜 일지도 만들 수 있어야 한다. 구분선 `||` 쓰는 법(키보드 `Shift+\` 두 번, 폰은 기호 자판)을 설명.

## 일지 줄 형식이 바뀐 과정
| 단계 | 형식 | 바뀐 이유 |
|---|---|---|
| 처음(11/02) | `- [[종목]] [등락:: 9.80] [[테마]] (사유:: …)` | Dataview 필요 |
| 1 | `- [[종목]] +n% [[테마]] · 사유` | 플러그인 없이 쓰려고. 표·배지는 이미 싫다고 함 |
| 2 | `- [[테마]] [[종목]](코드) +n% · 이슈` | 사용자가 "테마, 종목(코드), 등락률, 이슈 순서" |
| 3 | 테마 없으면 `none` → `Null` → `[[Null]]` | 미지정 표시. 끝에 링크로 |
| 4 | 구분선 `\|` → 두 개 → `\|\|` 한 자리 | 사용자 요청 ("한 자리에 두 개") |
| 5 | 테마·종목 진하게 → 둘 다 뺌 | 사용자 요청 |
| 6 | 종목과 코드를 한 링크 `[[종목\|종목(코드)]]` → 노트 이름을 `종목(코드)` 로 | 소스 모드에서 이름이 두 번 보임 |
| 7 | 이슈를 아랫줄 하위 항목 → `<br>` 한 줄 | 아랫줄은 검색 블록에 안 보임 |
| 확정 | `- [[테마]] \|\| [[종목(코드)]] +n%<br>이슈` | |

## 시도했다 버린 방법
- Remotely Save + OneDrive/Dropbox/R2 (Obsidian Sync 가 이미 있어서).
- 폰에서 Dataview 를 쓰게 하려고 플러그인 동기화를 켜는 방법 (제안만 함, 사용자가 코어 기능 쪽을 택함).
- 이슈를 하위 항목(`\t- 이슈`)으로 쓰기 → 노트 안 검색 결과에 이슈가 안 보임.
- 종목 이름에 별칭 링크 → 소스 모드에서 이중 표시.
- 이슈를 한 줄로 `· 사유` → 사용자가 "아래쪽에" 쓰길 원해서 `<br>` 로.

## 실수와 교훈
- **PowerShell 별칭**: 변환 스크립트의 도우미 함수 이름을 `Rd` 로 지었는데 `rd` 는 `Remove-Item` 의 별칭이라 함수보다 우선해, **11/02 일지 파일이 삭제**됨. 변환 직전에 만든 백업 zip 에서 바로 복원(7105바이트, 47줄 같음). 이후 함수 이름을 바꿈. 교훈: 함수 이름은 `ReadT`·`WriteT` 처럼 동사-명사 형태로, 별칭과 안 겹치게. 파일을 지우는 도구는 반드시 먼저 백업.
- **YAML 따옴표**: 템플릿 머리말 `날짜: {{date:YYYY-MM-DD}}` 는 YAML 에서 객체로 읽혀, 속성 편집기가 11/03 일지의 `날짜`를 깨뜨림. `날짜: "{{date:YYYY-MM-DD}}"` 로 따옴표를 붙여 해결. 11/03 머리말도 `날짜: 2026-11-03` 으로 고침.
- **일일 노트 템플릿 경로**: 설정 파일에 확장자 없이 `템플릿/일지 템플릿` 이라고 쓰면 "파일을 찾을 수 없습니다". `.md` 까지 필요하거나 화면에서 직접 고르기.
- **옵시디언이 켜진 채로 설정 파일을 고치면** 새 값을 못 읽을 수 있음. 설정은 화면에서.
- **비밀 노출**: Remotely Save `data.json` 을 읽다가 암호화된 설정 덩어리 `d` 항목이 대화 출력에 그대로 찍힘. 해독은 안 했고 실패. 이름이 `pass|token|secret|key|auth` 인 항목만 가렸기 때문. 교훈: 플러그인 설정 파일(`data.json`)은 값을 찍지 말고 키 이름만 본다.
- **백업**: 매 변환 전에 보관함 전체를 zip 으로 세션 임시 폴더에 백업했다 (영구 보관 아님).

## 기술 메모
- 코어 검색 블록: 종목 노트 `path:일지 "[[한싹(430690)]]"`, 테마 노트 `path:일지 "[[테마이름]]"`. 템플릿은 `{{title}}` 가 노트 이름으로 바뀜. 검색 결과에서 `<br>` 가 글자로 보이는지·폰에서 되는지는 미확인.
- 코어 템플릿 변수: `{{date:YYYY-MM-DD}}`, `{{title}}`. Templater 의 `<% %>` 와 다름.
- 테마 트리(PC 전용 Dataview JS): 줄 텍스트에서 `[[이름(코드)]] 등락률% <br>이슈` 를 정규식으로 읽음. 열어서 확인은 못 함.
- 일일 노트: 오늘만 만들고, 과거 날짜는 Calendar 플러그인(PC) 또는 `일지` 폴더에 날짜 이름으로 새 노트.
- 일지 머리말의 `날짜` 는 없어도 됨(트리·검색이 파일 이름을 씀).
- 형식 변경 때마다 변환은 PowerShell 스크립트로 일지 2개·종목 59·테마 18·템플릿·트리를 한 번에 처리. 변환 후 링크 대상 존재 검사(없는 대상 0개).
