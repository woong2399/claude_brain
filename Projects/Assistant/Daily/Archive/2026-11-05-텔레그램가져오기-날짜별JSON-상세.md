## 텔레그램 글 형태와 스크립트
- 글 맨 위 줄이 `📌 2일 월요일 상한가 및 급등주`처럼 `이모지 + N일 + 요일 + 상한가 및 급등주`. 이모지는 날마다 다름(🌺, 📌 등) → 정규식 `(\d{1,2})일\s*[월화수목금토일]요일\s*상한가\s*및\s*급등주` 로 찾음.
- 본문은 종목 블록 반복: `이름 / (코드) / (+등락률%) / 문장` 한 줄씩, 블록 사이 빈 줄. 코드에 영문 섞임(`18064K`, `0053F0`, `0015M0`, `0220W0`).
- 웹 미리보기의 `<time datetime>` 은 UTC → 한국 시간(+9)으로 바꿔 월·연을 붙임. 제목에는 월이 없음. 11/01 은 일요일이라 글 없음.
- 글 번호: 11/02 80295, 11/03 80391, 11/04 80516, 11/05 80603.
- 읽는 속도: 쪽마다 1.5초 쉼. 읽기 전용, 로그인·키 없음.

## JSON 만드는 규칙 (`build_daily_json.py`)
- 종목 집합 = Surge CSV 행 ∪ 텔레그램 블록 (코드 기준, 숫자만이면 6자리로 앞에 0 채움).
- `source`: `surge`(Surge 에만), `telegram`(텔레그램에만), `both`.
- `pct`: Surge 값이 있으면 그것, 없으면 텔레그램 값. `amount_est`: Surge 만 (텔레그램만이면 null).
- `issue`: 텔레그램 문장. `theme`·`news`: 시트 스냅샷(`sheet_news.json`)에서. 테마는 쉼표로 나눔, 뉴스는 `{headline, url}`(링크의 `utm_*` 제거).
- 정렬: `pct` 내림차순. 그 날짜 파일만 덮어씀.
- 오타 보정표 `FIX_THEME = {"전력저자장치(ESS)": "전력저장장치(ESS)"}` (사용자가 옵시디언에서 고친 값을 유지, 시트를 고치면 필요 없어짐).
- `sheet_news.json` 은 11/02 의 스냅샷만 있음(테마 있는 종목·뉴스 13건).

## Streamlit 시제품 (`daily_data\app.py`)
- 왼쪽: 날짜 선택, `전체 / Surge 10%↑만 / 텔레그램에만 있는 종목`, 등락률 하한 슬라이더, 뉴스 있는 종목만, 검색(종목명·코드·이슈).
- 카드: `#### 이름(코드) +등락률`(빨강), 테마·출처 캡션, 이슈 문장, 뉴스 목록(`[헤드라인](링크)`). 마크다운 특수문자는 이스케이프.
- 시험: Streamlit `AppTest`(예외 0, 카드 수 39, 11/02 뉴스 있는 종목만 13개) 와 브라우저 화면(localhost:8765) 확인 후 서버를 껐음.
- 실행은 `Documents\assistant\.venv` 의 streamlit 을 빌려 썼고 그 환경은 고치지 않음 (기본 Python 3.14·3.11 에는 streamlit 이 없음).
