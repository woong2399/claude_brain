# Surge

## 한 줄 설명
[[Projects/Storage/README|Storage]] 에서 수집한 일봉 중, 정규장 종가 기준으로 10% 이상 상승한 종목을 모두 추린다.

## 현재 상태
- 폴더만 만들었다. 2026-11-03 세션에서 작업 흐름(기준 → 문서 → SQL → 검증 → 저장 → 기록)을 정리했다. 아직 정하지 않은 것: 상승 기준, 기간, 제외 규칙, 필터, 결과 형태 (미확인).

## 다음 할 일
1. 기준 정하기: 전일 종가 대비 하루 상승률인지, 며칠 누적인지 / 기간(2015-06 이후 또는 전체) / 제외 규칙(신규상장 첫날, 거래정지 직후, 수정주가 변경일) / 최소 거래대금 등 필터 / 결과 형태(날짜별 목록, 종목별 횟수)
2. 조건을 `docs/` 에 적고, SQL 을 `code/` 에 둔다.

## 중요한 결정
- 데이터는 MotherDuck `woong_stock.daily`(정규장 수정주가)를 **조회만** 한다. 기존 DB 에는 쓰지 않는다.
- 추려진 종목 전체 목록은 볼트에 넣지 않는다 (행이 많아 동기화가 무거워진다). 요약과 통계만 둔다.
