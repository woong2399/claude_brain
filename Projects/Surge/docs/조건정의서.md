## 컬럼
| 컬럼 | 내용 |
|---|---|
| `date` | 날짜 |
| `code` | 종목코드 (앞자리 0 유지, 영문 섞인 코드 있음. 예: `0015M0`) |
| `name` | 종목명 |
| `pct` | 등락률(%) = (종가 / 전일 종가 − 1) × 100, 소수 둘째 자리 |
| `amount` | 거래대금, **백만 원** 단위 (종가×거래량과 비교해 확인). **주의: 2026-09-14부터 애프터마켓 거래대금이 섞인 값**(KRX 일봉 기준). 정규장만의 거래대금은 아님 ([[Projects/Storage/docs/data-collection]]) |

- **결정 (2026-11-04):** 거래대금은 일단 애프터마켓 포함 값 그대로 둔다. 정규장 값이 필요하면 로컬 분봉 합산 추정(`minute_bar_amount`) 또는 KRX 공식값(`krx_daily`, API 키 필요)을 쓸 수 있다.

## 매일 실행 (2026-11-04 결정)
- Storage 가 평일 16:00(`storage_update_1600`)·21:00(`storage_update_2100`)에 수집하고 MotherDuck 에 올린다.
- **16:00 수집이 끝나면 사용자가 "1600 끝났어"라고 알리고, Claude 가 `surge_daily.py` 를 돌린다.** 이 날부터의 `amount` 는 16:00 값이라 애프터마켓이 거의 빠져 있다 (11/02·11/03 은 애프터 포함이라 기준이 다름).
- 명령: `C:\Users\Jinwo\Documents\storage\.venv-md\Scripts\python C:\Users\Jinwo\Documents\surge\surge_daily.py [YYYY-MM-DD]` — 날짜를 생략하면 오늘.
- 동작: `storage.daily` 에 그날 1,000행 이상 있을 때만, `surge.main.picks` 그날 행을 지우고 다시 넣고, `YYYY년 M월 D일.csv` 를 만든다. 여러 번 돌려도 중복 없음. 휴장일·수집 전은 종료 코드 1.
