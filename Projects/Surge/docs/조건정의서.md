# Surge 조건 정의서 (잠정)

> "일단 2026-11-01부터"로 정한 잠정판. 기간은 나중에 넓힐 수 있다.

## 현재 적용 중인 조건
| 항목 | 값 | 비고 |
|---|---|---|
| 데이터 | MotherDuck `storage.main.daily`(정규장 수정주가), 종목명은 `storage.main.stocks` | **조회만** 한다 |
| 상승 기준 | 전일 종가 대비 당일 종가 상승률 ≥ 10% | 전일 = `daily` 에 있는 직전 거래일 |
| 기간 | 2026-11-01 이후 (11/01 은 일요일, 실제 11/02·11/03) | "일단" 이라고 했으므로 확장 가능 |
| 제외 규칙 | **없음** (미적용) | 신규상장 첫날은 전일 종가가 없어 자동으로 빠진다 |
| 필터 | **없음** (미적용). 우선주 포함 | 거래대금 필터는 `amount` 로 가능 |
| 결과 형태 | 날짜별 목록 | 종목별 횟수는 아직 안 뽑음 |

## 컬럼
| 컬럼 | 내용 |
|---|---|
| `date` | 날짜 |
| `code` | 종목코드 (앞자리 0 유지, 영문 섞인 코드 있음. 예: `0015M0`) |
| `name` | 종목명 |
| `pct` | 등락률(%) = (종가 / 전일 종가 − 1) × 100, 소수 둘째 자리 |
| `amount` | 거래대금, **백만 원** 단위 (종가×거래량과 비교해 확인). **주의: 2026-09-14부터 애프터마켓 거래대금이 섞인 값**(KRX 일봉 기준). 정규장만의 거래대금은 아님 ([[Projects/Storage/docs/data-collection]]) |

## 종가 기준
- `pct` 의 종가는 `storage.daily.close` = **정규장(09:00~15:30) 종가, 수정주가** (Storage 문서 기준, 애프터마켓 미포함). 직접 대조 검증은 안 함(미확인).
