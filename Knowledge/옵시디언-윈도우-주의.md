# 옵시디언·윈도우 작업 주의 (오래 쓸 사실)

2026-11-03 Daily 작업에서 겪은 일. 자세한 경위: [[2026-11-03-일지형식개편-동기화-상세]]

- **템플릿 머리말의 `{{ }}` 는 따옴표**: `날짜: "{{date:YYYY-MM-DD}}"`. 따옴표가 없으면 YAML 객체로 읽혀 옵시디언 속성 편집기가 값을 깨뜨린다.
- **코어 템플릿 변수**는 `{{date:YYYY-MM-DD}}`, `{{title}}`. Templater 의 `<% %>` 와 다르다.
- **일일 노트 템플릿 경로**는 `.md` 까지 필요하다 (`템플릿/일지 템플릿.md`). 설정 화면에서 직접 고르는 게 안전하다.
- **옵시디언이 켜진 채로 `.obsidian/*.json` 을 고치면** 새 값을 못 읽을 수 있다. 설정은 화면에서 바꾼다.
- **일일 노트 열기는 오늘 날짜만** 만든다. 다른 날짜는 Calendar 플러그인(PC)이나 날짜 이름의 새 노트.
- **PowerShell 에서 함수 이름이 내장 별칭과 겹치면 별칭이 이긴다.** `Rd` 는 `Remove-Item` 이라 파일이 삭제됐다. 도우미 함수는 `ReadT`, `WriteT` 처럼 짓고, 파일을 바꾸는 스크립트는 먼저 백업한다.
- **플러그인 설정 파일(`data.json`)은 값을 출력하지 않는다.** 암호화된 덩어리라도 로그인 정보가 들어 있을 수 있다. 키 이름만 본다.
- **Obsidian Sync 와 Remotely Save, Syncthing, OneDrive 를 같은 보관함에 같이 걸지 않는다.** 파일 충돌이 난다. 하나만 쓴다.
