# 구글 시트 연결 주의 (오래 쓸 사실)

2026-11-04 Daily 작업에서 안 사실. 경위: [[2026-11-04-구글시트-일지입력-상세]]

- Google Sheets·Google Drive 커넥터는 사용자가 **카드에서 직접 연결**해야 도구가 보인다. 연결 전에는 도구 검색에도 안 나온다.
- **시트에 값을 쓸 때 입력이 USER_ENTERED 처럼 해석된다.** `"004545"` 는 숫자 `4545` 가 되어 앞자리 0 이 사라진다. 숫자처럼 보이는 글자(종목 코드 등)는 **앞에 `'` 를 붙여** 쓴다 (`"'004545"`). 읽으면 `004545`.
- 날짜 `"2026-11-03"` 은 날짜 값이 되지만 `get_values` 로 읽으면 `2026-11-03` 으로 보인다.
- `get_values` 는 값을 보이는 모양 그대로(문자열) 돌려주고, 행 끝의 빈 칸은 빠져 배열 길이가 행마다 다르다.
- 빈 스프레드시트는 Drive `create_file` 에 `application/vnd.google-apps.spreadsheet` 만 주면 만들어진다 (탭 이름은 한국어 환경에서 `시트1`).
- 웹에 게시한 CSV 주소로 읽는 방법은 **주소를 아는 사람 누구나 볼 수 있어** 쓰지 않는다.
