# 주식 비서(Assistant) 환경 주의 (오래 쓸 사실)

2026-11-05 Assistant 작업에서 안 사실. 경위: [[2026-11-05-장전보고서-구축-상세]]

- **MotherDuck 은 duckdb 최신(2.0.0)을 아직 지원하지 않는다.** 파이썬에서 연결하려면 `duckdb==1.5.6` 처럼 지원 버전으로 고정한다.
- **Streamlit 은 `--server.address` 를 안 주면 PC 전체 주소로 열린다**(외부 주소가 표시됨). 폰 접속용이면 Tailscale 주소로만, 아니면 `127.0.0.1` 로 연다.
- **Tailscale**: PC 와 폰에 설치하고 같은 계정으로 로그인하면 `100.x.x.x` 주소로 접속된다. PC 의 주소는 `Get-NetIPAddress` 에서 `Tailscale` 인터페이스로 확인.
- **야후 시세 주소는 비공식**이지만 지수·VIX·금리는 FRED(공식)와 일치했다. 유가·금·구리는 선물 근월물이라 현물(FRED 유가)과 3~4% 달랐다. 값마다 기준 날짜를 같이 적는다.
- **investing.com, BLS 일정 페이지는 코드 요청이 403** 으로 막힌다. 봇 차단은 우회하지 않는다(사용자가 코드를 줘도). 공개 일정표는 브라우저 화면에서 사람처럼 한 번 읽어 표로 옮긴다.
- **DART 공시 목록 API**: `opendart.fss.or.kr/api/list.json`, 하루 약 500건, 100건씩 페이지. 시장 구분 `Y` 코스피, `K` 코스닥. 정정 공시는 제목 앞에 `[기재정정]`. 인증키는 `.env` 에만 둔다.
- **Claude 의 자동 권한 검사는 작업 스케줄러 등록, 프로세스 종료를 막을 수 있다.** 사용자가 직접 실행하거나 허용 규칙을 추가해야 한다.
- **미국 행사는 미국 동부시간 기준**(11월 첫 일요일 이후 EST). 한국 시각으로 바꿀 때 `zoneinfo`(Windows 는 `tzdata` 패키지 필요)를 쓰면 서머타임이 자동 반영된다.
